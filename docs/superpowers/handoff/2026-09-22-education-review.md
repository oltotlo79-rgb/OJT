# v1.2.0 教育機能と3D操作の確認記録

利用者の追加依頼に基づく単独作業。サブエージェントは使用せず、Astra視点で操作・状態・保存互換性・異常終了・表示と実行の整合を再点検した。独立した別エージェントによるレビューではない。

## 不具合と対策

| 指摘 | 修正 | 再発を検出する検査 |
| --- | --- | --- |
| キューブが上下の角度上限で止まる | 球座標の制限をやめ、位置と上方向を同時に回転 | 26方向×上下左右×2周で毎ステップの移動量・距離・直交を検査。実画面で正面・真下から縦横1周 |
| 中断操作をクリックと誤認する | pointercancelはスナップせず、blurも操作状態を復旧 | 中断後の操作可否・慣性復旧・ストア書込なし |
| 回転後にプリセットを選ぶと昔の位置から始まる | 現在のカメラ位置を遷移開始点にする | 自由回転位置を与えて遷移の0フレーム目を検査 |
| 反対側への遷移で盤の中心を横切る | 姿勢を球面補間し、距離を保つ | 180°切替の全途中姿勢で距離と上方向の長さを検査 |
| FX5Uなのに特殊リレーが旧FXのM表記 | SM400系を正規表記にし、旧入力は互換として受理 | 正式番号・互換番号・全角をパースして実行 |
| JTEKTの常時ONがV4で入力できない | V004/V005/V006、V4などの省略入力を受理 | 直接入力と用途選択を実画面で操作 |
| 特殊接点のウォッチがM0等の値を読む | 特殊リレーを別のスナップショットへ格納 | M0とSP0が逆の値でも混同しない |
| 初期パルス・クロックのモニタが次スキャンの値になる | 実行済みスキャンの値を返す | 1・2・50・51・100・101スキャンを含む連続検査 |
| 未実行・リセット直後でも初期パルスをONと表示する | 実行済みスキャンがない間は特殊接点の観測値を返さない | 初期状態→1・2スキャン→リセットを2周し、未測定表示と出力を検査 |
| 測定E2Eが操作前のOLを2回読んだだけで確定する | 期待する読値への切替と安定の両方を必須にする | 正常抵抗・コイル断線・レアショート・PB4押下と解放を5回連続検査。5秒上限と再実行0回を維持 |
| JWの007366を直接入力すると常時ONになる | 007366は常時OFF。常時ON用途はb接点で作成 | 4メーカー4用途の入力→実行→再編集、JW旧IRのa/b/P/Fとの動作一致 |
| ヒント第3段が測定・PLCでも「配線する1本」 | モードに合う確認手順へ変更 | 点検・修復・PLC、1級の段数制限、課題固有説明の優先 |
| 文字130%で目次3か所と時間列4か所が折り返す | 目次幅を文字倍率に追従させ、表の見出しに必要な幅を確保 | 全4モードの拡大表示で改行・文字切れ等を0件に制限 |
| 拡大表示の指摘が別ファイルだけに残り、全体集計が0件になる | 通常表示と同じrecordへ集計し、重要度だけで検査から除外しない | 拡大表示単独の実行でも基準0の項目は失敗し、全体集計にも反映 |
| 一覧の読込中に検査・撮影を進められる | 一覧表の表示完了と描画を待ち、拡大表示も全画面の画像を保存 | 実際の一覧とヘルプの撮影画像を照合 |
| 拡大時に「難しさ」と数字が別行になる | 級・難しさ・時間・IDは1行に保ち、長い課題名・説明の列で折り返す | 一覧の補助列も文字の行数を計測する対象へ追加 |
| 発行日テストのGit一時フォルダが終了直後のWindowsロックで消せずpushを停止 | 他の一時フォルダ検査と同じ上限付きのロック解除待ちを追加 | 削除エラーを握りつぶさず、上限内に削除できなければ引き続き失敗 |
| main CIで保存検査用のPowerShell起動が10秒を超え、実ロックの準備前に失敗する | 検査の準備待ちを30秒、検査全体を60秒に分離し、実ロック成立を引き続き必須にする | 保存成功時の実ファイル置換、失敗時の元内容保持、50・100・200msの待機値と一時ファイル削除は従来どおり検査 |

## 特殊接点の資料と確認範囲

番号だけでなく接点の極性を確認した。資料にない機能を実機準拠と断定しない。

- 三菱：[FAQ 24172](https://fa-faq.mitsubishielectric.co.jp/faq/show/24172?site_domain=default)でFX5UのSM400/SM8000を確認。[MELSEC iQ-Fカタログ](https://www.mitsubishielectric.com/dl/fa/document/catalog/plcf/l08428/l08428-d.pdf)の特殊リレー一覧でSM401・SM402・SM412とFX互換エリアを確認。
- ジェイテクト：[公式トレーニング項目](https://toyoda.jtekt.co.jp/support/training_stepfigure.html)でV004・V005・V006を確認。TOYOPUC-PCS T-331、Plus Safety T-386のメーカー作成資料では常時ON・常時OFF・初期パルス。PC10Gの公式マニュアルは認証が必要で全文未取得のため、PC10G全機能の照合完了とはしない。V072は既存の模擬クロックを継続し、新たに一次資料確認済みとは扱わない。
- オムロン：[CP1E W479-E1-11](https://www.omron.com.tw/data_pdf/mnu/w479-e1-11_cp1e.pdf)のP_On/CF113、P_Off/CF114、P_1s/CF102。初期パルスは既存のA200.11を継続。
- シャープ：[JW300ラダー命令編、2・7](https://jp.sharp/sms/pdf/plc/jw300/m_jw300l_5.pdf)で007366は常時OFF（b接点で常時ON）、007362は初期パルス、007364は1秒クロック。

特殊デバイスは4種類の教育用模擬動作。実機の全特殊リレー、通信・診断レジスタ、実機転送は対象外。旧作業ファイルのSP0〜SP2は意味を変えず、常時OFFをSP3として追加した。

## 画面と配布

3Dは主光源による部品の影と十字溝のある共有ネジ形状を追加する。影を落とす対象をソケット・装着部品へ限定し、描画予算の基準は緩めない。特殊接点は接点入力中だけの選択欄と説明文に収める。ヒントの説明リンクから、予測・測定・観測・判断の教材へ移動する。

リリース前の検査結果・配布物SHA256はOJT/release/verificationへ記録する。単体テストだけで完了とせず、画面E2E・PDF描画・ポータブルEXE・対象SHAのCIを確認してから公開する。

v1.2.0は最終の拡大表示の照合で上記7件を検出したため、下書きのまま未公開とした。修正を含むv1.2.1を最終配布版とし、対象コミットの検査・ビルド・配布EXE確認をやり直す。v1.2.0の成功ログをv1.2.1の検証結果として流用しない。

v1.2.1のmain CIで保存テストの準備待ちが失敗したため、この版も公開せずv1.2.2へ検査修正を反映した。失敗箇所はwriteFileAtomicの呼出し前であり、製品の保存時の待機上限は350msのまま変更していない。検査の再実行で失敗を隠す設定も加えていない。
