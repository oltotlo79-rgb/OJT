# v1.4.0 電源機器・直接操作の単独レビュー

## 対象

利用者の指摘：初期配線が不要、P端子の出線が分かりにくい、ブレーカーと電源スイッチの形状が分かりにくい、3D品質の改善が伝わらない、配線・測定・作業順を柔軟にしたい。

Codexがサブエージェントを使わず、実装・モデル・実操作・画面を個別に見直した。実物の参考写真は `docs/reference/K96-CS3-board-photo.png`。左のDC24V出力部は開放型の端子台として再現し、写真にない大型電源箱にはしない。

## 発見と対策

| 発見・原因 | 修正 | 再発防止 |
| --- | --- | --- |
| 部品点検用の固定3本を組立とPLCにも初期追加していた | 課題モードで明示的に初期配線を選択 | 全120組立・PLC課題のゼロ本、全部品点検課題の3本を照合 |
| 模範回路の端子割付も固定配線を前提とし、削除だけではPB4の給電が欠落する | 回路図割付と生成セッションで同じ初期配線条件を使用 | PB4接点を使う独立した回路図から、P側・接点・コイル・N側の配線を検査。全模範解答も再検査 |
| P/N端子に汎用端子台が重なり、電線が筐体内へ沈んで見える | 専用端子台の形状と左への出線経路を変更 | 正逆方向のP端子出線検査、配線経路の衝突・ストレス検査、実描画の拡大画像 |
| ブレーカーとスイッチが類似した箱に見える | 2極ケース＋レバーと、I/O付きロッカーを分ける | 4モードの3D入切操作、ON/OFF拡大画像、共有ジオメトリと待機描画の検査 |
| 操作帯のボタン出現でキャンバスが縮み、選択中の端子が移動する | 最小高さを統一して操作帯をキャンバスの外へ分離 | 配線開始・測定切替前後の実キャンバス寸法をE2Eで照合 |
| 組立中にテスターを使う入口がなく、初回の計測手順が分かりにくい | 測定ボタン、黒赤切替、測定値、明示解除を追加 | ネジの実クリックでN/P間24Vを測定。空白クリック後も値を保持 |
| 電線2本の端子がリストで選べず測定できない | 配線上限と測定可否を分離 | 2本接続したP端子を測定時に選べることを検査 |
| 組立の作業保存にテスターが含まれていない | 設定・プローブの保存とWorker再起動時の再送 | 保存→読込→Worker送信、つまみOFFでプローブを置いた状態の再送を検査 |
| 測定値にVが2回表示される | 既に単位を含む読値へ単位を追加しない | 実測表示画像を確認 |
| 手順表示が前段の完了を要求し、自由に進めた作業が反映されない | 個別の作業状態で進捗表示し、手順から道具へ移動 | 報告前に修復した場合の進捗、組立の配線・部品への移動を検査 |
| 新しい手順ボタン「判定」が実行ボタンと同じ名前 | 移動ボタンの読み上げ名を「判定へ移動」にする | 画面品質監査の重複操作名チェックを維持 |

## 検査方針

対象テストの失敗を期待値だけで隠さず、配線を前提にする既存テストでは点検用回路を明示的に構築する。未配線の新仕様は独立したテストで確認する。既存の保存データに含まれる固定配線は削除しない。

説明書の操作一覧・メッセージ一覧との厳密な一致、型検査、Lint、全単体テスト、実操作E2E、複数画面寸法の監査、最終画面からの説明書撮影、PDF、配布EXE、対象コミットのCIを公開条件とする。検査ログと配布物照合結果は `OJT/release/verification/v1.4.0-*` に保存する。

ソフトウェア描画環境での60fps測定は性能の受入根拠にしない。実行しないGPU試験は記録に明記する。モデルは教育用の再現であり、実機との寸法認証は行っていない。
