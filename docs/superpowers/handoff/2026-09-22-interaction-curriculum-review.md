# v1.3.0 操作・教材拡充の単独レビュー

ユーザー指示に従い、サブエージェントを使用せず、Astraの観点で操作・教材の正しさ・再発防止・配布を点検した。別エージェントによる独立レビューではない。

## 発見と修正

| 問題 | 修正 | 再発防止 |
| --- | --- | --- |
| 盤面のドラッグが回転や誤配線になり、移動意図と一致しない | 通常ドラッグを平行移動へ統一。配線・取り外しのドラッグはAlt併用 | 左右中ボタン、正面・俯瞰・底面、端子上の操作で位置・向き・距離・配線数を実測 |
| キューブ回転を初回ガイドが認識しない | 実際の回転完了をガイドへ通知。クリック・中断は完了にしない | 初回の全手順を実画面操作し、再起動後の完了保持まで検査 |
| カメラの検査値だけ注視点の丸め桁数が粗い | 位置と同じ精度で記録 | 角度保持の許容差を緩めず数値比較 |
| ヒントの途中段階では閉じられない | 表示の開閉と段階の進行を分離。閉じる・Esc・外側クリックを追加 | 全段階の開閉、再表示で段数不変、フォーカス復帰、画面内への収まりを検査 |
| PLCの手順がボタンに見えても押せない | 配線・ラダーの手順を実ボタンへ変更 | 実画面で切り替え、ラダーの保持を照合 |
| 部品カードから未選択ソケットの一覧へ戻れない | 小さな「ソケット一覧へ」を追加 | リレーとタイマを連続装着するE2Eで検査 |
| 3D部品の外形だけでは構造が伝わらない | リレー内部、タイマの筐体・目盛、盤の縁と脚を追加 | 材質ごとに形状を共有・結合。部品を装着して描画予算を検査 |
| 明るいタイマケース上で既存の白い印字が読みにくい | 印字・目盛を暗い色に変更 | 拡大と俯瞰の画像で確認 |
| 説明書に「真下には回り込めない」と旧操作が残る | 360°回転、平行移動、Alt操作、ヒントの開閉を同期 | 操作要素・用語・章リンクを既存の厳密照合に含める |
| 説明書の過度な平仮名表記 | 画面・説明書・目次・検索参照を合わせて漢字表記へ統一 | 代表語の表記検査と生成内容の同期検査 |
| 模範解答同士の比較だけでは教材の仕様誤りを検出できない | 独立した真理値式とタイマの期待値を追加 | 新規組立・PLCの全80題を照合。短押し2回で累積計時の誤りも検出できる操作列 |
| 課題追加時に修復・測定の検査から漏れる | 新規C2の全修復手順を登録し、全接点故障の測定を追加 | 未修復・指摘漏れ・部分修復の失敗と、DCVでの観測差を検査 |

| 課題の正本だけ増え、同梱フォルダと説明書の索引が旧件数のまま | 教材生成時に同梱フォルダと索引も同期 | 全216題のID・本文・索引を照合。配布EXEでもモード別件数を確認 |
| 新設した3級の初期表示で、既存の指定課題がテストから見えない | ID指定の操作では全級を明示してから開く | 撮影・点検・結果復帰・出力の全経路を実画面で検査 |

## 課題構成

回路組立60、部品点検36、回路点検・修復60、PLC60、合計216。既存IDと課題は保持した。追加JSONの原稿は `packages/content/scripts/build-expanded-curriculum.mjs`、生成した教材は通常の静的JSONとして同梱する。実行時の課題生成ではない。

各メーカーの機能追加は今回行っていない。特殊接点と一次資料の照合範囲は前回の教育レビューを継承する。3Dの内部構造は学習用の模式形状で、メーカーの製造図面そのものではない。

## 公開前の門

型検査・lint・全単体検査、画面E2E、改行や切れの監査、説明書の図・PDFの文字と内部リンク、梱包されたEXEの実動作、mainとタグの最新CIを確認する。公開ツールは対象SHAと配布EXEのハッシュが一致しなければ拒否する。検証記録とハッシュは `OJT/release/verification` に保存する。

Git名義と認証アカウントは変更せず、既存のOJT内worktreeを使用する。配布フォルダへはポータブルEXEを1個だけ置く。以前に削除を拒否された作業フォルダは再試行や別手段で回避しない。
