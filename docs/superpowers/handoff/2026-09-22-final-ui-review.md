## 見つけた問題と物的対策

| 重要度 | 問題 | 修正と再発防止 |
| --- | --- | --- |
| Important | 重なった窓の親を先に閉じると、Escの対象や本文のスクロール復帰が壊れる | 共通の窓ID集合で最上位・スクロールロックを管理。順不同の破棄、二重解除、元のoverflow復帰をテスト |
| Important | C1・C2・PLCで3Dの電源操作が動かない経路が残る | 全4モードを同じ電源コマンドへ接続。3Dを実際に押し、上の帯の入切表示までE2Eで検査 |
| Important | PLCの部品パレットから運搬できない | 既存の装着・取外し・履歴処理へ接続。カードからCR1への実ドラッグを検査 |
| Important | 配線ドラッグ中にアプリを切り替えると仮選択や回転ロックが残る | pointercancelとblurで中断。運搬中の元部品は外さない。中断後の配線取消と次の視点回転を実画面で検査 |
| Important | 部品や端子上の中・右ボタンを編集操作と誤認し、平行移動を妨げる | 編集は左ボタンに限定。既存のShift＋中ドラッグ・ホイールによる視点操作を再検証 |
| Important | SVG全体の縮小で回路図・目盛・チャートの文字が12pxを下回る | 実測表示寸法から文字の最小値を確保。波形目盛と抵抗目盛は重なる数値だけ間引く。空の回路図の母線名は外側へ配置。既存の波形・目盛・回路図テストと画面監査で検査 |
| Important | PLC分割画面の3列がラダー編集領域を圧迫する | 左列を盤と道具、右列を編集面に変更。1279px以下の縦積みは維持。実幅の検査と4メーカー・3解像度の画面監査 |
| Minor | 未定義のCSS変数で文字色が意図しない値になる | 参照先を修正。未定義かつ代替値のないCSS変数を静的検査し、毎回のpushゲートへ追加 |
| Minor | 一部のチェック操作や図の拡大操作の当たり領域が小さい | 32px以上を確保。radio/checkboxは関連labelの実クリック領域も測定し、ラベル端からのクリックをE2Eで検査 |
| Minor | 盤の端とビューキューブの裏でラベルが欠ける | 視野外とキューブ占有領域をラベルの配置判定へ追加。キューブを72pxへ縮小し、丸ボタンは32pxへ拡大 |
| Minor | 点検モードで装着部品のドラッグ表示だけ出て実際には移動できない | C1はトレイ、C2は修復の交換操作に対応させ、未対応の運搬開始を出さない |
| Minor | 電線3本目の扱い、PLC画面配置・キー、IPC本数の説明が古い | 実装と説明書・本体仕様を同期。説明書の操作網羅・固定文言検査を再実行 |
