# v1.7.0 使いやすさ改善 Implementation Plan

> **For agentic workers:** `AGENTS.md` によりサブエージェントは使わない。このセッションで superpowers:executing-plans の要領で1タスクずつ実行する（TDD、タスクごとに日本語コミット）。Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 設計 `docs/superpowers/specs/2026-09-26-v1-7-0-usability-design.md` を実装し、v1.7.0 を公開する。

**Architecture:** 経路と配線規則は `@ojt/board-model` の純関数で直し（3Dはその結果を描くだけ）、画面の操作は `apps/desktop` の純関数（`session/*.ts`）＋部品で足す。動画・説明書は実アプリを操作する既存スクリプト（`record-tutorials.mjs`・`manual-shots.spec.ts`）を拡張して作り直す。

**Tech Stack:** TypeScript 6 / React 19 / three.js（R3F）/ zustand / Vitest / Playwright(Electron) / electron-builder

**作業場所:** `OJT/.worktrees/phase7`（ブランチ `codex/phase7-acceptance`、公開は `git push origin HEAD:main`）。検証記録は `OJT/release/verification/v1.7.0/`。

**共通の検査コマンド**
- パッケージ単体: `pnpm --filter @ojt/<pkg> exec vitest run <file>`
- 型: `pnpm typecheck` ／ Lint: `pnpm lint`
- 画面: `pnpm --filter @ojt/desktop build` の後 `pnpm --filter @ojt/desktop exec playwright test --project=default <spec>`
