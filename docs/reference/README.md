## 写真から観察した配置

- 傾斜コンソール型筐体（手前低く奥に立ち上がり）
- 上部左 DC24V 端子台、上部右ブレーカ
- 上段の DIN レールに 14ピンソケットが左右各4個（計8個）
- 中段 DIN レール上、ランプ・押ボタンの手前に各機器の両極を引き出した接続端子台（左 8P、右 12P）
- 下段 左に PL1〜PL4（白・黄・緑・赤）、右に PBS1〜PBS4（黒・黄・緑・赤）
- 端子台から PL・PB 本体へ青線の既設配線
- ダクト無し（空中配線）
