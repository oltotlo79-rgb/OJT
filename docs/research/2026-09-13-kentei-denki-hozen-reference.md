## 1. 実技試験の構成（1級・2級、3級との違い）

### 1.1 課題の種類

| 級 | 課題1 | 課題2 |
|---|---|---|
| 1級 | PLC（プログラマブルコントローラ）による回路組立作業<br>**入力3点・出力4点** の配線 | ①リレー・タイマの点検 ②有接点シーケンス回路の点検および修復作業<br>**回路図は与えられず、当日指示のタイムチャート図をもとに** 点検・修復 |
| 2級 | PLCによる回路組立作業<br>**入力3点・出力3点** の配線 | ①リレー・タイマの点検 ②有接点シーケンス回路の点検および修復作業<br>**回路図（有接点シーケンス回路）が問題に提示される** |
| 3級 | **有接点シーケンスによる回路組立作業**（PLC不使用）<br>**入力2点・出力2点** の配線、リレー・タイマを用いる | ①リレー・タイマの点検 ②有接点シーケンス回路の点検および修復作業<br>**回路図＋タイムチャート図の両方が提示される** |

出典: 1級 <https://www.kikaihozenshi.jp/pdf/2025/2025_1kyu_denki__jitugi_mondai.pdf> / 2級 <https://www.kikaihozenshi.jp/pdf/2025/2025_2kyu_denki_jitugi_mondai.pdf> / 3級 <https://www.kikaihozenshi.jp/pdf/2025/2025_3kyu_denki_jitugi_mondai_1.pdf>

### 1.2 試験時間（1級・2級 共通の「実技試験の概要」より）

| 課題 | 標準時間 | 打切り時間 |
|---|---|---|
| 課題1 | 50分 | 60分（標準時間 50分＋10分） |
| 課題2 | 30分 | 50分（標準時間 30分＋20分） |

- 集合から試験終了まで **180分程度** を要する。
- 標準時間を超えた場合、超過時間に応じて減点される（打切り時間までは作業続行可）。

補足: JIPM「試験要項」ページでは電気系保全作業の実技試験は **1級・2級・3級とも110分・2課題・作業採点（一部マークシート方式）** と記載されている。これは打切り時間の合計（60＋50＝110分）と一致する。 <https://www.kikaihozenshi.jp/points/>

### 1.5 PLC に関する重要な制約（アプリ設計に直結）

- 試験開始前に **受検者自身で空プログラムをPLCへ書き込み・読み出し** し、プログラムが残っていないことを技能検定委員が確認する。これができない場合、課題1に進めない。
- **PLCは試験用盤上に配置できない**（机上に置いて作業）。
- 試験中は無線LAN（Wi-Fi含む）をOFFにする。
- **試験用盤のAC100VおよびDC24VをPLCの電源として使用してはならない**。
- 入出力モジュールの接続部は **端子台を推奨**。コネクタ式PLCの場合は中継用端子台を設ける。
- 事前に作成したプログラムの閲覧・読込み、試験後のプログラム持ち帰りは **不正行為として失格**。

出典: <https://www.kikaihozenshi.jp/pdf/2025/2025_2kyu_denki_jitugi_gaiyo-mondai.pdf>（p.4）

### 1.6 採点項目（公式）

| 採点項目 | おもな採点ポイント |
|---|---|
| 工具 | 指定された仕様・規格の工具を用いて、正しく使用できているか |
| 安全および作業態度 | 安全に配慮して作業を行っているか（**活線作業など**）／作業終了後、整理整頓されているか |
| 仕様動作 | 仕様どおりに動作するか |
| 作業時間 | 所定の時間内に作業を終えたか（標準時間超過は超過時間に応じて減点） |
| 回路点検 | 不具合の箇所を正しく特定できているか |
| 回路組立 | 配線は適切に行われているか／**圧着は適切に行われているか** |

出典: <https://www.kikaihozenshi.jp/pdf/2025/2025_2kyu_denki_jitugi_gaiyo-mondai.pdf>（p.5）

補足（教育機関資料。公式の採点細目ではない）:
- 活線作業（電源ONのまま配線する／回路に触れる）は「即OUT」。
- 切りくずの散乱（机上・机回り・検定盤上）、工具・材料の落下は減点対象。
- 課題2の修復で、不良箇所以外を変更するのは「改造」となり失格。
- 出典: <https://www.edu-ctr.pref.nagano.lg.jp/kjouhou/jousan/sangyou/shiryou/kougyo/eh-nyumon.pdf>

### 1.7 動作確認〜採点時の禁止事項

- 挙手した後は、技能検定委員が指示する作業（電源のON-OFF、盤上の押しボタン操作）以外はできない。
- **配線の修正、リレー・タイマの抜き差し、タイマの設定変更は不可**。
- 自分で動作確認が必要な場合は、挙手する前に行う。

出典: <https://www.kikaihozenshi.jp/pdf/2025/2025_2kyu_denki_jitugi_gaiyo-mondai.pdf>（p.7）

│                            −/+ 端子                  入 / 切                              │

│   │  CR1   │  CR2   │  CR3   │  CR4   │        │ チェック用 │  ← 14ピンソケット×5      │
│   │  (4c)  │  (4c)  │  (4c)  │  (4c)  │        │   (4c)    │                            │
│   └────────┴────────┴────────┴────────┘        └──────────┘                  │

- **課題1用の配置**: ソケット4個が `CR1 / CR2 / CR3 / CR4`（いずれも 4c）＋ `チェック用` 1個。
- **課題2用の配置**: ソケット4個が `CR1 / CR2 / T1 / T2`（いずれも 4c）＋ `チェック用` 1個。
- ランプは **白・黄・緑・赤** の4個、押しボタンスイッチは **黒・黄・緑・赤** の4個。
- ランプ用端子台は `+ / −` が4組（8端子）。押しボタン用端子台は `c / a / b` が4組（12端子）で、**1つのスイッチでa接点・b接点のどちらにも使える**（c=COM, a=メーク, b=ブレーク）。
- ランプ・押しボタンと端子台の間は **あらかじめ配線済み**（課題2で「異常はないもの」と明記される範囲）。

出典: <https://www.kikaihozenshi.jp/pdf/2025/2025_2kyu_denki_jitugi_gaiyo-mondai.pdf>（p.3, p.4）、押しボタンのc/a/b端子の意味は <https://www.edu-ctr.pref.nagano.lg.jp/kjouhou/jousan/sangyou/shiryou/kougyo/eh-nyumon.pdf>

### 2.3 制御電源電圧

- 制御回路は **DC24V**。盤上に「DC24V電源（制御用電源）」があり、回路図の母線は `P(+24V)` / `N(0V)`。
- 盤への給電は **AC100V**（プラグ→サーキットブレーカ(1A)→DC24V電源）。
- 表示ランプも **DC24V用**、リレー・タイマも **DC24V用**。
- 出典: <https://www.kikaihozenshi.jp/pdf/2025/2025_2kyu_denki_jitugi_gaiyo-mondai.pdf>

> **設計メモ**: 「AC100Vか DC24Vか」の答えは明確で、**制御回路はすべてDC24V**。AC100Vはプラグ〜ブレーカ〜DC24V電源の一次側だけ。3Dアプリでは一次側は「配線済み・触れない領域」として扱えばよい。

### 2.4 3級の試験用盤（参考）

3級では試験場に **課題1用としてリレー2個・タイマ2個、課題2用としてリレー4個・タイマ2個** が付属する構成が案内されている。盤は木製または金属製、ランプ・押しボタンは金属製取付金具で固定、ソケットはレールで固定、盤にはゴム足、ブレーカ〜コンセント間にスイッチがある。
出典: <https://www.edu-ctr.pref.nagano.lg.jp/kjouhou/jousan/sangyou/shiryou/kougyo/eh-nyumon.pdf>

### 4.3 圧着・端子締付けの作法（教育機関資料）

- 電源を切って作業を開始する。
- **圧着端子の歯型（圧着痕）が見える向きに差し込む**。
- **二本差すときは背中合わせで差し込む**。
- ねじはなめないように締める。「ただ回すのではなく押しながら回す」＝**押し7、回し3**。
- **下の段から作業する**。
- 配線が終わったらケーブルを整える。

出典: <https://www.edu-ctr.pref.nagano.lg.jp/kjouhou/jousan/sangyou/shiryou/kougyo/eh-nyumon.pdf>

### 4.4 配線の順序・取り回し（教育機関資料）

1. ケーブル作りは **適切な長さ** で作成する（長すぎ・短すぎはNG）。
2. 配線の順番: ① **GNDライン（13番の −端子）** → ② 距離の長い箇所 → ③ 距離の短い箇所。配線が交差すると見た目が悪くなる。
3. **課題1ではリレー・タイマを一番最後に差し込む**。前後左右から浮きがないことを確認する。
4. **課題2の回路修復では、リレー・タイマは差し込んだまま修復する**。
5. ケーブルは中心にまとめる。

出典: <https://www.edu-ctr.pref.nagano.lg.jp/kjouhou/jousan/sangyou/shiryou/kougyo/eh-nyumon.pdf>

### 4.5 二本差し（渡り配線）の扱い

- シーケンス図を実配線に落とすとき、**1つの端子に2本の圧着端子を挿す箇所が発生する**（例: 押ボタンの＋端子とリレーの13番端子）。この場合は **ケーブルを背中合わせにして配線する**。
- 出典: <https://www.edu-ctr.pref.nagano.lg.jp/kjouhou/jousan/sangyou/shiryou/kougyo/eh-nyumon.pdf>

## 5. 回路組立て課題のタイムチャート（課題1）

### 5.1 出題形式

- 問題文は「試験用盤と持参したPLCを用いて、入力n点および出力m点の配線を行い、回路を完成させ、作動する状態にしなさい」という形式。

- さらに、一部の出力ランプ（2級: 黄ランプ・緑ランプ／1級: 黄ランプ・緑ランプ・赤ランプ）の仕様は **試験当日に指示** される（事前公開版では波形が空欄で「（当日、仕様を指示する）」と記載）。

### 5.2 タイムチャートの信号構成

| 級 | 入力（上段） | 出力（下段） |
|---|---|---|
| 1級 | 黒押しボタン / 黄押しボタン / **緑押しボタン** | 白ランプ / 黄ランプ＊ / 緑ランプ＊ / 赤ランプ＊ |
| 2級 | 黒押しボタン / 黄押しボタン / **緑押しボタン（リセット）** | 白ランプ / 黄ランプ＊ / 緑ランプ＊ |
| 3級 | 押しボタン 2点 | ランプ 2点（黄ランプの仕様は当日指示） |

＊ = 事前公開版では「（当日、仕様を指示する）」と空欄。

- 白ランプの波形のみ事前公開されており、押しボタンの立ち上がりから白ランプが変化する位置が破線矢印で示される形式。
- 2級の事前公開版では「仕様1」「仕様2」の2パターンが掲載され、仕様2には `3秒` の時限要素が含まれる。
- 1級の事前公開版では黄押しボタンの各パルスに `0,1,2,3,4` と **回数の番号** が振られており、**押した回数による動作（カウント／順次動作）** が要求されることが読み取れる。

出典: <https://www.kikaihozenshi.jp/pdf/2025/2025_2kyu_denki_jitugi_mondai.pdf>（p.3）、<https://www.kikaihozenshi.jp/pdf/2025/2025_1kyu_denki__jitugi_mondai.pdf>（p.3）

### 5.3 課題1の条件（公式・1級/2級共通）

- タイムチャートの **始まりと終わりは論理「0」** とする。
- プログラムおよび配線は **繰り返し運転ができること（再現性があること）**。
- 試験用盤の AC100V および DC24V を PLC の電源として使用しないこと。
- **PLCからの出力は、試験用盤上のリレーを介すること**。
- **PLCからの電源を利用してリレーを駆動させないこと**。

出典: <https://www.kikaihozenshi.jp/pdf/2025/2025_2kyu_denki_jitugi_mondai.pdf>（p.2）

> **設計メモ**: 「PLC出力 → 盤上のリレー → ランプ」という**2段構成が必須**。つまり出力点数分のリレー（2級3個／1級4個）を課題1で使う。これは公式の機材表「課題1用リレー 4（1級）/ 3（2級）」と完全に整合する。3Dアプリの課題1モードはこの結線モデルをそのまま実装すればよい。

### 5.4 3級 課題1（有接点シーケンスによる回路組立）

- 「試験用盤とリレー・タイマを用いて、入力2点および出力2点の配線を行い、回路を完成させた後、作動させなさい」。
- 黄ランプの仕様は試験当日に指示。条件は「タイムチャートの始まりと終わりは論理0とする」。
- 出典: <https://www.kikaihozenshi.jp/pdf/2025/2025_3kyu_denki_jitugi_mondai_1.pdf>（p.2）

### 5.5 典型回路（教材ベースの基本回路一覧）

長野県教育センターの検定対策資料が挙げる基本回路（3級入門編）:

| # | 回路 | 概要 |
|---|---|---|
| 1 | a接点 | 通常開。リレー動作で閉（ランプ点灯） |
| 2 | b接点 | 通常閉。リレー動作で開（ランプ消灯） |
| 3 | AND回路 | 2つのスイッチが押されるとリレー動作 |
| 4 | OR回路 | どちらかのスイッチでリレー動作 |
| 5 | **自己保持回路** | 起動信号でリレー動作、停止信号まで保持。停止接点を先頭に置く形（有接点向き）と、起動を先頭に置く形（PLC向き）の2通り |
| 6 | **先行優先回路（インターロック回路）** | 相反する動作が同時発生しないようにする |
| 7 | **新入力優先回路** | 後から入った入力を優先 |
| 8 | 三路スイッチ回路 | 2箇所のスイッチでON→OFF |
| 9 | **オン・ディレイタイマ回路** | 起動後、設定時間後に動作 |
| 10 | **オフ・ディレイタイマ回路** | 停止信号後、設定時間後に開放 |
| 11 | **ワンショット回路** | 起動後、設定時間だけ動作 |
| 12 | **フリッカ回路** | ON→OFFを繰り返す |

有接点回路での重要な注意（同資料）:
- ワンショット回路で **タイマのコイルを自身の接点で切断する回路は動作が不安定になるので厳禁**。必ずリレーを介す形にする。
- フリッカ回路も **タイマ2個だけで組む形（PLCでは有効）は有接点では厳禁**。タイマ回路内部の復帰時間が必要なため、**リレーを使って復帰時間を確保する**。
- 出典: <https://www.edu-ctr.pref.nagano.lg.jp/kjouhou/jousan/sangyou/shiryou/kougyo/eh-nyumon.pdf>

> **設計メモ**: この2点は「実機リレーとPLCシミュレーションの挙動差」そのもの。アプリで有接点モードを作るなら、**タイマの復帰時間（H3Yの Rt = 0.1s以上）をモデル化** して、教科書どおりの"厳禁回路"がちゃんと不安定になるようにすると教育効果が高い。<https://www.marutsu.co.jp/contents/shop/marutsu/datasheet/omron_H3Y.pdf>

## 6. 故障探索課題（課題2）

### 6.1 課題2の2部構成

**① リレー・タイマの点検**
- 与えられたリレー・タイマを点検し、**良・不良の判定ならびに不良原因を解答用紙（マークシート）に記入**する。
- 条件:
  - チェック用ソケットの配線（黄色）を変更しないこと
  - 点検は **回路計（テスタ）と試験用盤のチェック用ソケット** を用いて行うこと
  - **a接点溶着によるb接点の導通不良の異常内容は「a接点の溶着」** とする
  - **b接点溶着によるa接点の導通不良の異常内容は「b接点の溶着」** とする

**② 有接点シーケンス回路の点検および修復作業**
- 2級: 提示された回路図をもとに、試験用盤を点検し **不良箇所のみを修復** し作動する状態にする。
- 1級: **試験当日に指示されたタイムチャート図をもとに** 点検・修復する（回路図は与えられない）。
- 3級: 回路図とタイムチャート図の両方が提示される。
- 前提: **ランプおよび押しボタンスイッチと端子台の間、チェック用回路の黄色の配線には異常はない** ものとする。
- 条件:
  - リレー・タイマは①で **良品と判定したものを使用** すること
  - 修復箇所は **指示された白色の線を新たに加工して配線** すること
  - 不良箇所として配線（青色）を取り外した場合、**取り外した線を切断・折り曲げ・ペン等でマークしない**
  - 盤上のソケットや配線類にペン等でマークしない

出典: <https://www.kikaihozenshi.jp/pdf/2025/2025_2kyu_denki_jitugi_mondai.pdf>（p.4）、<https://www.kikaihozenshi.jp/pdf/2025/2025_1kyu_denki__jitugi_mondai.pdf>（p.4）、<https://www.kikaihozenshi.jp/pdf/2025/2025_3kyu_denki_jitugi_mondai_1.pdf>（p.3）

### 6.2 リレー・タイマの不良原因（公式の選択肢6種）

| # | 不良原因 | リレー | タイマ |
|---|---|---|---|
| 1 | **コイルの断線** | ○ | ○ |
| 2 | **コイルのレアショート** | ○ | 教育資料では「タイマにはレアショートは無い」とされる【要確認】 |
| 3 | **メーク接点（a接点）導通不良** | ○ | ○ |
| 4 | **メーク接点（a接点）溶着** | ○ | ○ |
| 5 | **ブレーク接点（b接点）導通不良** | ○ | ○ |
| 6 | **ブレーク接点（b接点）溶着** | ○ | ○ |

出典（選択肢6種）: <https://www.kikaihozenshi.jp/pdf/2025/2025_2kyu_denki_jitugi_mondai.pdf>（p.4）
出典（タイマにレアショートは無い）: <https://www.edu-ctr.pref.nagano.lg.jp/kjouhou/jousan/sangyou/shiryou/kougyo/eh-nyumon.pdf>

### 6.3 リレー・タイマの良否判定手順（教育資料）

| チェック状況 | 判定される不良原因 |
|---|---|
| リレーが **ON** のとき a接点 導通なし | **a接点 接触不良（導通不良）** |
| リレーが **OFF** のとき a接点 導通あり | **a接点 溶着** |
| リレーが **ON** のとき b接点 導通あり | **b接点 溶着** |
| リレーが **OFF** のとき b接点 導通なし | **b接点 接触不良（導通不良）** |

手順:
1. スイッチ（赤PBS）をONにしたとき、コイルが動作し鉄片が吸引されることを確認。動作しなければ **コイル断線**。
2. a接点・b接点の各端子を確認（OFF時: b導通・a不導通、ON時: a導通・b不導通）。1つでも異常なら接点不良。
3. **レアショートの確認**: 正常動作に見える場合でも念のためコイルの抵抗値を測定する。**正常コイルの抵抗値は650Ω程度**。これより小さければレアショートと判断。（DC24Vコイルの場合）

出典: <https://www.edu-ctr.pref.nagano.lg.jp/kjouhou/jousan/sangyou/shiryou/kougyo/eh-nyumon.pdf>

### 6.5 テスタの使い方（2系統）

**(A) 無通電での導通／抵抗測定**

- **リレー・タイマは外す**（配線の仕方で回路の回り込みが起こり、測定できないため）。
- **電源をOFFにする**（スイッチ「切」でもよいが、コンセントを抜くことが望ましい）。
- 手順:
  1. リレー・タイマ・ランプの配線端子番号を回路図に記入する。
  2. 「P」ラインの配線を (＋) からたどり、どこに繋がっているか／端子番号は何番かを回路図に記入。配線が途切れていれば **未配線**。
  3. 「N」ラインの配線を (−) からたどり、同様に記入。
  4. テスタのリード棒を起点(⓪)に固定し、もう一方を①→②→…と移動して測定。反応があればOK、なければ **断線**。
  5. 同じことを線番号ごとに繰り返す。マークチューブに線番号がある場合はP,1,2,…,N の順で追う。
- 熟練者向け: P/Nライン確認後、リレー・タイマを取り付けて実際に動作させ「どこまで動くか」で故障箇所を予測してから絞り込む。

**(B) 通電状態での電圧測定**

- **リレー・タイマを取り付ける**。回路は DC24V で動作している。
- **テスタのリード棒で回路に触れることは活線作業ではない**（※**手で触ればアウト**）。
- 手順:
  1. 回路を動作させ、どこまで動作するかを観察して怪しい回路を特定する。
  2. リード棒(黒)を基準点(⓪)に固定し、リード棒(赤)を①→②→③…と移動して電圧を測る。
  3. 「電圧あり」→その区間は問題なし。「電圧なし」→その手前の区間が **断線か未配線**。
  4. 自己保持がかかっていない回路は、測定のたびに押しボタンを押さないと電圧が測れない点に注意。

**(C) 電源ON/OFFの手順と安全**

- 電源 ON時: **ブレーカ → スイッチ**。OFF時: **スイッチ → ブレーカ**。
- ブレーカはスイッチではない。ケーブル途中のスイッチを「電源スイッチ」と考える。
- 課題2のリレー・タイマ不良判別時は、**電源ONのまま差し替えOK**。
- 修復チェック時: **導通・抵抗値でチェックする場合はOFF**、**電圧でチェックする場合はON**（端子には素手で触れないこと）。

出典（A〜C）: <https://www.edu-ctr.pref.nagano.lg.jp/kjouhou/jousan/sangyou/shiryou/kougyo/eh-nyumon.pdf>

> **安全上の注意（アプリでの再現価値が高い）**: 「電源ON状態で抵抗／導通レンジを当てる」のはテスタ破損・誤測定の原因。上記資料も **導通・抵抗測定は必ず電源OFF** と明記している。アプリでこれをやったら測定値が化ける／テスタのヒューズが飛ぶ、という挙動を実装すると教育的。

### 6.6 解答の形式

- リレー・タイマの点検結果（良・不良の判定と不良原因）は **解答用紙（マークシート）** に記入する。
- JIPM「試験要項」でも電気系保全作業の実技は「作業採点（**一部マークシート方式**）」と記載されている。
- 出典: <https://www.kikaihozenshi.jp/pdf/2025/2025_2kyu_denki_jitugi_mondai.pdf>、<https://www.kikaihozenshi.jp/points/>
- **【未確認】**: マークシートの具体的な様式（リレー/タイマ番号 × 良否 × 不良原因6択のマトリクスか等）は非公開。

## 7. PLC（シーケンサ）課題

### 7.1 出題形式

- タイムチャート（当日指示される1パターン）を満たすラダープログラムを作成し、PLCに書き込み、盤と配線して動作させる。
- 1級: 入力3点・出力4点 / 2級: 入力3点・出力3点。
- 出典: <https://www.kikaihozenshi.jp/pdf/2025/2025_1kyu_denki__jitugi_mondai.pdf>、<https://www.kikaihozenshi.jp/pdf/2025/2025_2kyu_denki_jitugi_mondai.pdf>

### 7.2 盤とPLCの標準的な入出力配線

公式の制約から導かれる標準結線:

```
[入力側]
 盤 DC24V(+) ──→ PLCの入力COM（またはPLC側の入力電源）※PLC電源は盤から取らない
 押しボタン端子台 c/a  ──→ PLC 入力端子 X0(=黒PBS), X1(=黄PBS), X2(=緑PBS)

[出力側]
 PLC 出力 Y0/Y1/Y2(/Y3) ──→ 盤上ソケット CR1/CR2/CR3(/CR4) のコイル端子(13-14)
     ※「PLCからの出力は、試験用盤上のリレーを介すること」
     ※「PLCからの電源を利用してリレーを駆動させないこと」→ リレーのコイル電源は盤のDC24Vを使う
 CRn の a接点(9-5等) ──→ ランプ端子台 +/− 経由で 白/黄/緑(/赤) ランプ
```

- 条件の根拠: <https://www.kikaihozenshi.jp/pdf/2025/2025_2kyu_denki_jitugi_mondai.pdf>（p.2）
- PLC側コモン端子の渡り線および電源は **事前配線可**: <https://www.kikaihozenshi.jp/pdf/2025/2025_2kyu_denki_jitugi_gaiyo-mondai.pdf>（p.4）

> 1. 内部モデルは **ベンダー中立の中間表現**（接点/コイル/タイマ(単位はms統一)/セット・リセット/微分）で持つ。
