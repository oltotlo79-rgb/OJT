#### 端子台の構成（AC電源タイプ）

ハードウェアマニュアルの「3.4.2 入力の接続例［AC電源タイプ］（DC24Vサービス電源使用時）」の図から、端子名と並びは次のとおり。
出典: https://dl.mitsubishielectric.com/dl/fa/document/manual/plcf/jy997d53401/jy997d53401jj.pdf

| ブロック | 端子（図の上から） | 内容 |
|---|---|---|
| 電源 | `L` / `⏚`（D種接地） / `N` | AC100〜240V 入力。`⏚` は機能接地端子 |
| サービス電源・入力コモン | `S/S` / `0V` / `24V` | DC24Vサービス電源出力（24V, 0V）と入力コモン切換端子 S/S |
| 入力 | `X0` `X1` `X2` `X3` …（8進、X0〜X17） | 入力16点 |

- **シンク入力**：`S/S` と `24V` を短絡し、入力コモンを＋側にする（図1.シンク入力）。
- **ソース入力**：`S/S` と `0V` を短絡し、入力コモンを−側にする（図2.ソース入力）。
- DC電源タイプでは電源端子が `⊕` / `⏚` / `⊖` になる（3.4.3 入力の接続例［DC電源タイプ］）。
- 出典: 同ハードウェアマニュアル 3.4.2 / 3.4.3

出力端子台は、上段・下段を半ピッチずらした千鳥2列。マニュアルの「4. 端子台配列／仕切り線の見方（例：FX5U-32MT/ES）」に次の模式図がある。

| 段 | 並び（左→右） |
|---|---|
| 上段 | `Y0` `2` `・` `Y4` … |
| 下段 | `COM0` `1` `3` `COM1` … |

- `・` は空端子、太い縦線が**仕切り線**で「同じコモンに接続されている出力の範囲」を表す。
- 出典: https://dl.mitsubishielectric.com/dl/fa/document/manual/plcf/jy997d53401/jy997d53401jj.pdf （4. 端子台配列）
- **FX5U-32MR/ES の具体的な端子並び順・コモン分割（COM0/COM1/…が何点ずつか）は【未確認】**。ハードウェアマニュアル「MELSEC iQ-F FX5S/FX5UJ/FX5U/FX5UC ユーザーズマニュアル（ハードウェア編）SH-082451」に記載があるが、同PDFはFAメンバーズ会員限定 URL（`/dl/fa/members/...`）で取得不可。

#### 変換 → 書込み → 実行の操作フロー（公式ガイド）

出典: 「MELSOFT GX Works3 FBクイックスタートガイド」L(名)08474 https://dl.mitsubishielectric.co.jp/dl/fa/document/catalog/plceng/l08474/l08474-b.pdf

1. **変換／全変換**：作成完了したプログラムを実行させるには変換が必要。プログラム作成初回は**全変換**を行う。「変換」は前回変換時から変更のあった部分のみを変換する。
   - メニュー ［変換］→［全変換］ を選択 → メッセージ表示 → すべてのプログラムが変換され、**結果が「出力ウィンドウ」に表示**される。
2. **シーケンスプログラムの書込み**：メニュー ［オンライン］→［シーケンサへの書込み］ を選択 →「オンラインデータ操作」ダイアログ → シーケンサへの書込み実行。
3. **モニタ**：`F3` でモニタモードに切換え、`Shift+F3` でモニタ（書込みモード）に切換え（上表）。
4. 表示系の例: メニュー ［表示］→［コメント表示］にショートカット割当あり（同ガイド「ガイドの見方」）。

### 5-5. 実装上の示唆（3D／ラダーエディタ設計向け）

1. **端子台の描画モデル**は3種類に分類できる。
   - FX5U・CP1E: 一体形、**千鳥2列**のネジ端子台（上段・下段を半ピッチずらす）。上段/下段の並びを配列で持ち、`COM`／空端子／仕切り線をメタデータとして持つ設計が合う。
   - JW300・TOYOPUC I/Oモジュール: **着脱式端子台**、`A`グループ 0〜7＋`COM.A` ／ `B`グループ 0〜7＋`COM.B` の 18端子（JW300）、8点/COM（TOYOPUC IN-12）。**8点1コモン**が共通パターン。
   - 電源・接地端子は FX5U が `L`/`⏚`/`N`、JW300 電源ユニットが `L`/`N`/`GND`、CP1E が `L1`/`L2/N`（入力端子台側に同居）と、いずれも位置が異なる。
2. **シンク／ソースの扱い**: FX5U は `S/S` 端子の接続先（24V＝シンク／0V＝ソース）で切り替わる仕様が明示されており、3D配線演習の題材に最適。CP1E・JW300・TOYOPUC はコモン極性の扱いが異なる（JW-212NA は「コモン極性なし」）。
3. **AC100Vランプの直接駆動**は FX5U-32MR/ES（AC240V以下・2A/点）、CP1E-N30DR-A（AC250V/2A）、JW-214SA（AC250V・2A/点）、TOYOPUC OUT-12（AC240V・2A/点）いずれのリレー出力でも可能。教材の「ランプ直結」演習は4機種共通で成立する。
4. **ラダーエディタのモード設計**: GX Works3 は「書込み／読出し／モニタ／モニタ（書込み）」の4モードと明示的な「変換」が必要。CX-Programmer はオフライン時の変換が不要。この差はUIモデルに直結するので、機種ごとに「変換ステップの有無」をフラグ化するとよい。
5. **進数の差**が最大の学習ポイント。JW300は8進のリレー番号（`007364` など）、TOYOPUCは16進かつプログラム番号プレフィクス（`1M000`）、CP1Eは「CH.ビット」の10進表記（`100.07`）、FX5UはX/Yのみ8進。デバイス入力欄のバリデーションは機種ごとに別実装が必要。
