# 電気教育ツール v1.8.2

## 3D表示の修正

- ランプ用・押ボタン用端子台では、ネジから台座の外まで配線を上面に見せてから盤面へ下ろします。渡り線・既設の青線・同じ端子への2本目にも適用します。
- 端子台のカバーを台座の外形内に収め、接続部を覆っていた名札を3Dの銘板へ変更しました。
- リレーソケットは外側の端子列、内側の端子列、中央の差込面に段差を付けました。ネジ・圧着端子・端子番号も各列の高さに合わせています。
- 高い列と低い列を続けて配線しても、出線の高さが衝突しないように割り当てます。
- 拡張盤の追加端子台と既設配線にも、同じ外形・出線位置の処理を適用しました。
- PLCへ渡る配線にも台座の外から下ろす処理を適用しました。4メーカーの端子台・ソケット接続を確認しています。
- ソケット拡大表示に部品の高さを反映し、端の部品が画面外へ切れる問題を修正しました。段見出しと色帯の描画順も修正しています。

## 検証

- 端子台・ソケットの形状と配線の検査37件、盤モデルの全280件、型検査が成功しました。PLCとの接続は4メーカー・272パターンを確認しています。
- Electron実画面の操作検査20件が成功しました。配線・削除・部品装着・電源操作に加え、リレー装着後の全14端子の選択も別途確認しました。
- 説明書の画面操作9件が成功し、原寸72図・縮小72図とPDFを更新しました。図の仕上げ処理は低負荷設定に合わせて制限時間を延ばし、保存済みの撮影元から完了しました。
- Setup版・Portable版の生成と同梱検査が成功しました。配布EXEの4検査で、起動・372課題の読込み・回路の合格・保存復元・同時起動・終了処理を確認しました。
