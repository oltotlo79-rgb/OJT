# 電気教育ツール v1.9.0

端子と電線のつながりを見分けやすくし、動画で作業前の仕様確認から案内します。ポータブル版の起動表示も、本体の画面が準備できるまで残します。

## 主な変更

- 電線をネジの横から圧着端子を介して接続します。同じ端子から2本出る場合は出口を分け、マークチューブを直線部分に置きます。ソケットの段へ線が潜る表示を修正し、配線同士の重なりと余分な折り返しを避けます。
- 既設線・盤内線・PLC線を一緒に整理します。多本数の自由配線で後の電線の出口が塞がる問題も修正しました。接続・線色・故障・採点に使う配線データは保持します。
- 組立・部品点検・点検修復・PLC4社の動画7本を撮り直しました。作業前に課題文、タイムチャートまたは点検項目を赤線や赤枠で強調し、完成条件と最初の作業を説明します。点検修復ではマークチューブと回路図の照合も示します。
- 動画の説明・操作の待ち時間を約15%増やし、再生速度に0.5倍を追加します。0.75倍・1倍・1.25倍・1.5倍も選べます。字幕と動画の速度変更を合わせて使えます。
- ポータブル版は起動画像を先に読み出せる圧縮設定を明示して固定しました。起動画面は、本体のホームまたは読込エラー画面が描画され、ウィンドウが表示されるまで保持します。設定と一時保存の確認が終わる前に起動完了と扱う問題も修正しました。終了時の展開先の片付けと、同時起動の分離は維持します。
- 取扱説明書・ヘルプの配線、マークチューブ、動画操作の説明と画像72枚を更新しました。点検修復の完了図は、故障した青線の取り外しと白線2本の修復を実際に操作して撮影し、手順と画像説明を揃えました。PLCの配線出口の説明も機種ごとの形状に合わせました。

## 検査時の警告

テストでThree.jsをCommonJSとして読み込む補助コードには非推奨警告が出ます。アプリの画面はES Modulesのビルドを使用します。課題検査のNode.jsの型変換に関する実験的機能の警告と、検査プロセスの色出力指定（FORCE_COLOR / NO_COLOR）の警告もあります。いずれも検査用の実行環境に関する警告です。検査失敗を無視したり、配布版のエラーを抑制したりしていません。

## 今回行っていないこと

実機PLCへの接続、純正PLCソフトとの連携、利用先のPCでの起動計測、実機GPUの60fps試験は行っていません。アプリはオフラインの練習用シミュレーターです。起動時間はPCの性能やウイルス対策ソフトなどの環境によって変わります。
