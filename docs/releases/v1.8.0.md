# 電気教育ツール v1.8.0

## 3D図の操作と配線

- 選択した電線を `Delete` と `Backspace` のどちらでも外せます。入力欄で文字を消すときには配線を変更しません。電線一覧には、選んだ電線を直接外すボタンも追加しました。
- 配線モードで電線と端子が重なる場所を押したとき、端子を優先して選ぶようにしました。電線の途中を押したときは電線を選べます。
- リレーソケットを段差のある形に変更し、ネジ端子から出る電線をソケット表面より上に引き出しました。ソケット外で盤面の配線層へ下ろすため、電線が本体の内部に埋まって端子から離れて見える状態を解消しました。
- ソケット付近の横方向と縦方向の配線を高さで分け、同じ列から出る電線も段を分けました。配線帯のレーンに加え、ソケット上の電線の交差を検査します。
- 1本の経路が描けないときの代替描画で、机上の電線を誤って盤内経路エラーとして数えないようにしました。

## 課題

- 回路組立 B-101〜102、部品点検 C1-065〜066、回路点検・修復 C2-101〜102、PLC D-101〜102を追加しました。非常停止を繰り返した後の復帰と、2回の自動停止後の手動停止を練習します。内蔵課題は B 102題、C1 66題、C2 102題、D 102題の計372題です。

## 確認

- 型検査・lint・単体テスト、全内蔵課題の検証、実画面の操作テストを実施しました。
- Windows x64 のインストーラー版とポータブル版を生成し、配布物からの起動と操作を確認しました。
- 検証時に Three.js の CommonJS 読み込み、Node.js の型変換機能、Playwright の色設定について警告が出ます。いずれも検証の終了コードに影響せず、現行版の起動も確認済みです。Three.js の警告は将来の依存ライブラリ更新時に再確認します。

## やっていないこと

- 実PLCとの通信、ACV測定、ワード演算は引き続き未対応です。
- 実機GPUでの60fps計測、オフライン環境でのインストール、OS標準ビューアでのPDF表示は、この版では確認していません。
