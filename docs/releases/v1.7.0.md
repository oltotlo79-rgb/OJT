# 電気教育ツール v1.7.0

## PLCの机上配線

- PLCの3D図で、電線がPLC本体を貫通して見える不具合を直しました。端子カバーは、一体形（三菱・オムロン）は本体の上下に平らに倒し、ラックの形（ジェイテクト・シャープ）は取り外した状態で描きます。PLC本体の下段の端子へは、電線が本体の下から入ります。電線がほかの端子のねじや本体の前面を横切らないことを、全内蔵PLC課題×4メーカーで自動検査しています。
- 盤の左上のP・N端子から机上へ出る電線が、隣のN端子の上に重なって見える不具合を直しました。電線はいったん左へ逃がしてから机上へ出ます。
- 3D図の画面のまま、右の欄の「メーカーを切り替える」でPLCのメーカーを切り替えられるようにしました。切り替えても盤の中の配線・部品・ラダー・デバイスコメントは残り、外れるのはPLC本体と壁コンセントへの電線だけです。窓に、外れる本数と残る本数が出ます。
- PLCの課題でも仕様のタイムチャートを見られるようにしました。手順の帯の「タイムチャートを見る」で課題の欄のチャートへ移り、「拡大」で大きく表示できます。モニタ中は「ライブ記録」に実際の動きが流れます。

## 1つの端子は2本まで

- すべての課題・盤で、1つの端子につなげる電線を2本までにそろえました。2本つながった端子へ3本目をつなごうとすると、3D図の上に「注意：1つの端子に接続できる電線は2本までです」と注意文が出て、つながりません。危険操作としては数えません。
- 自由練習用の拡張盤の既定（1端子4本）と、課題作成画面の本数の選択をなくしました。以前の課題ファイルに3本以上と書いてあっても2本として扱います。

## 回路点検・修復

- テスターの棒を当てた場所が3D図で分かるように、黒と赤の棒を立て、先に「黒 CR1⑬」のような端子名の札を出すようにしました。棒の根元には色の輪が付きます。隣り合う端子に当てても札は重なりません。
- 故障の指摘を3D図の中でできるようにしました。「指摘」を選んで電線・端子・部品を押すと、押した場所の横に小窓が出て、断線・誤配線・未配線・部品不良を選べます。部品不良は、コイルの断線・接点の溶着などの内容まで選べます（合否は場所で決まり、内容は結果の画面で講評します）。電線一覧の「この電線の故障を指摘」、修復の欄の「この部品の故障を指摘」からも同じ小窓が開きます。

## 課題の追加

- 各モードに10題ずつ追加しました（回路組立100題・部品点検64題・回路点検・修復100題・PLC100題、計364題）。非常停止・自動停止・遅延起動・警報の確認・順次起動・長押し・一時停止・両手操作・再起動の禁止・運転時間帯を題材にしています。

## 操作の総点検で直したこと

- PLC本体・壁コンセントへつないだ机上の電線を、3D図で押して選び `Delete` で外せなかった不具合を直しました。
- 画面の下の知らせ（トースト）が出ている間、その下のボタンが押せなかった不具合を直しました。
- PLC・点検修復の画面にも、盤の左上に配線の始点と選んだ電線、3D図の下に「押すと何が起きるか」の案内を出すようにしました。
- 4メーカーのPLC本体の全端子を3Dで押して配線の始点にできること、机上の電線を選んで外せること、3本目の注意文、メーカー切替後も盤内の配線が残ること、3D図の指摘の小窓を、実画面の自動操作で検査するようにしました。

## 動画・取扱説明書・ヘルプ

- PLCの解答操作動画を、三菱に加えてジェイテクト・オムロン・シャープの分も作りました（計4本）。メーカーごとの端子名・デバイスの書き方・記号の置き方で、同じ課題 D-001 を最後まで解きます。練習画面からはいま使っているメーカーの動画が開き、動画の画面でほかのメーカーへ切り替えられます。
- 回路点検・修復の動画を撮り直し、3D図の電線を押して指摘する方法と、電線一覧から指摘する方法の両方を説明しました。回路組立・部品点検の動画も新しい画面で撮り直しました。
- 取扱説明書とヘルプの図を42枚から72枚に増やしました。新しい機能（メーカーの切替、4メーカーの机上配線、PLCのタイムチャート、3本目の注意文、テスターの棒と札、3D図の指摘の小窓と講評）と、端子リスト・電線一覧・判定表・測定記録・キーの早見表・特殊接点・スキャン診断などの図を足し、手順を番号付きの1手1行に整えました。「困ったときは」に「押しても思ったとおりにならないとき」を足しました。
