# 電気教育ツール v1.6.1

## 電線の取り外しの不具合修正

- 電線を選んで `Delete` を押しても電線が外れない不具合を修正しました。これまでは上の帯の「削除モード」に切り替えたときしか `Delete` が効かず、右の欄の「電線一覧・接続先の変更」で選んだ電線や、通常の状態で選んだ電線は外れませんでした。電線が選ばれていれば、どの状態でも `Delete` で外れます。
- 取扱説明書のとおり、「削除モード」に切り替えなくても3Dの電線の途中をクリックして選べるようになりました。端子・部品・押しボタンと重なる所では、これまでどおりそちらを優先します。配線の始点を選んだあとに電線を押しても、配線は取り消されません。
- 電線一覧のチェックボックスを押したあとでも `Delete` が盤へ届くようにしました。
- 電線の選択は `Esc` か、盤の何もない所のクリックで外せます。
- 固定電線は、これまでどおり外せません。
- ヘルプとPDF取扱説明書の「電線をつなぐ・外す」「回路点検・修復」の手順を更新しました。

## 継続して利用できる内容
