# 電気教育ツール v1.9.2

回路点検・修復で、外した青線を1本ずつ戻し、登録した指摘を変更できるようにしました。操作ログと経過時間は初期状態で折りたたみ、3D図を広く使えるようにしました。

## 主な変更

- 回路点検・修復の「外した青線」に「元に戻す」を追加しました。開始時の両端・線色・線番・故障状態を復元し、ほかの修復や指摘は保持します。端子の3本目になる復元は止め、復元自体も上の帯の「元に戻す」「やり直し」で取り消し・再実行できます。
- 指摘一覧に「変更」を追加しました。現在の選択を強調した小窓で種類や部品不良の内容を選び直せます。「取消」やEscで変更をやめても登録済みの指摘は残ります。場所を変える場合は、一覧で取り消して新しい場所を指摘します。
- 全4モードの操作ログ・経過時間を開閉できる欄にまとめ、初期状態で閉じるようにしました。閉じている間もログの件数、経過時間、警告件数を表示し、記録と計測は続きます。組立・点検・修復では3D図の表示範囲が広がります。
- 3Dの電線の断面を細かくし、曲面の見た目を滑らかにしました。配線の経路、接続、線色、故障、判定のデータは保持します。
- ポータブル版の起動案内を、展開処理のウィンドウから独立させました。展開前に表示し、本体のウィンドウが表示され、実際の描画内容を確認してから閉じます。本体の空白画面に隠れないよう、起動案内は準備が整うまで手前に保持します。
- 組立・部品点検・回路修復・PLC4社の動画7本を新しい画面で撮り直しました。操作ログの開閉を示し、回路修復では指摘変更と青線の個別復元を実演します。説明枠は操作対象を隠さない位置へ移します。
- 取扱説明書・ヘルプに復元と指摘変更の実画面を追加しました。タイムチャートの位置とPLCの命令語リストを書き出す欄の古い案内も、実際の操作に合わせました。

動画の作業前の課題文・タイムチャート・点検項目の確認、説明・操作を少しゆっくり見せる待ち時間、0.5倍・0.75倍・1倍・1.25倍・1.5倍の再生速度は引き続き利用できます。
