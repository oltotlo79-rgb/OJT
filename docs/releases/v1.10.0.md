# 電気教育ツール v1.10.0

ホームに「回路実験」と「PLC実験」の2つのモードを追加した版です。押ボタンの押し方と正解のランプの動きをタイムチャートに描き、組んだ回路（PLC実験はラダー）を動かして、ランプがどう動くかを確かめます。動かした結果を正解に取り込めば、自分で作った問題として判定にも使えます。

## 主な変更

- ホームのモードを6つにしました。「回路実験」「PLC実験」のカードは課題一覧ではなく「実験を始める」窓を開き、はじめのタイムチャート（空か例題4題）と、PLC実験では盤の配線（配線済みの盤／自分で配線する盤）を選びます。
- 練習の画面の右の欄に「タイムチャート実験」を追加しました。描いた押し方・正解と、最後に動かした結果を小さいチャートで重ねて見せ、正解と違う所を赤い帯で示します。「大きく開いて編集」「動かす」「盤で動きを見る」「配線をやり直す」をここから使えます。判定は上の帯の「判定」1か所です。
- 「タイムチャートを描く」窓では、押ボタン4行・ランプ4行をドラッグで塗ります（0.1秒刻み。点いている所から引くと消す）。行ごとの区間の一覧から秒を打ち込んでも描け、長さ（2〜60秒）・例題の読み込み・押し方と正解の消去・判定に使うランプの印・「この結果を正解にする」（確認付き）を備えます。
- 判定は、描いた正解と動かした結果を許容差（0.2秒、または区間の長さの1割）で見比べ、1端子の本数・コイル極性・電源操作手順・禁則回路を確かめます。PLC実験ではPLC電源の独立と二段構成も見ます。線色ルール・未使用部品・I/O割付は実験なので見ません。結果画面・動きの見直し・見くらべ・書き出しも実験で使えます。
- 例題4題（自己保持・インターロック・オンディレー・ワンショット）は、内蔵課題の模範回路・模範ラダーを元の押し方で動かした結果を正解にしています。どの例題も元の課題の模範で合格することを確かめています（PLCは4メーカー）。
- PLC実験の配線済みの盤は、リレー4個を装着し、盤とPLCの電線をすべて固定電線で張った状態です（入力0〜3番がPB1〜PB4、出力0〜3番がCR1〜CR4を通ってPL1〜PL4）。「配線をやり直す」で配線済みの盤と自分で配線する盤を選び直せ、メーカーを切り替えると新しい機種の端子名で張り直します。
- 実験はその場で作る練習で、課題一覧・課題ファイルには入りません。描いたタイムチャートとラダーは自動保存と作業ファイルに入り、続きから開けます。
- 取扱説明書に「回路実験・PLC実験」の章を追加し、ホームの説明・困ったとき・ヘルプの案内を合わせました。解答操作動画に回路実験（2分59秒）とPLC実験（3分06秒）の2本を追加し、全9本になりました。
- 実験の結果画面は、見比べる相手が模範回路ではなく描いた正解であることが分かる言い方にしました（まず直すところ・差分一覧・書き出し・「正解と見くらべる」の窓）。
- 画面品質の点検で見つかった次の点を直しました。特大表示（130%）でホームの「基本例題の動画」のボタンが語の途中で折り返す、チャートの実測幅が半端なとき文字が12px未満に縮む。

## 検査時の警告

テストでThree.jsをCommonJSとして読み込む補助コードには非推奨警告が出ます。アプリの画面はES Modulesのビルドを使用します。課題検査ではNode.jsの型変換に関する実験的機能の警告も出ます。いずれも検査用の実行環境に関する警告です。配布物を作る段階で出る警告は、検証フォルダのログに残します。検査失敗を無視したり、配布版のエラーを抑制したりしていません。配布EXEは未署名です。

## 今回行っていないこと

実機PLCへの接続、純正PLCソフトとの連携、利用先のPCでの起動計測、実機GPUの60fps試験は行っていません。アプリはオフラインの練習用シミュレーターです。回路実験・PLC実験で描いたタイムチャートは、課題一覧に加えたり課題ファイルとして配ったりはできません（自動保存と作業ファイルには入ります）。押ボタンは4個、ランプは4個の範囲で描きます。動画は代表フレームの確認で、全フレームの目視ではありません。
