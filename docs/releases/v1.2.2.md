# 電気教育ツール v1.2.2

ビューキューブの全周回転、メーカー別の特殊接点、学習解説と3D部品の描画を改善しました。v1.2.0とv1.2.1は最終検証で修正が必要だったため未公開とし、修正を含むv1.2.2を配布します。

## 変更点

- キューブは上下・左右とも真上・真下・裏面を越えて回転します。つかみ直し、操作中断、プリセットへ戻る際の視点の飛びも修正しました。
- 三菱SM400・SM401・SM402・SM412、ジェイテクトV004（V4）・V005・V006などを接点へ入力できます。用途から選び、その場で意味を確認できます。
- 常時ON・常時OFF・初期パルス・1秒クロックの4種類に対応。監視値を内部リレーと区別し、シャープ007366のa/b接点の意味と旧作業ファイルの互換性を修正しました。
- ヒントを配線・部品点検・故障修復・PLCの作業内容に合わせました。ヘルプと説明書に測定による切り分け、自己保持、特殊接点の点滅回路、学習の振り返りを追加しました。
- 3Dのネジに十字溝と面取りを加え、部品の影で奥行きを分かりやすくしました。
- 文字サイズ130%でもヘルプ目次と一覧表の見出し・補助列が不自然に折り返さないよう修正しました。拡大表示の指摘を全体集計へ含め、再発時はCIを失敗させます。
- Windows CIの保存テストで、補助プロセスの準備待ちと製品の保存時間の検査を区別しました。実ロック成立、保存内容の保持、製品の350ms上限は引き続き検査します。

## 確認範囲

型検査・lint・全単体テスト、実画面E2E、PDFの文字・内部リンク・描画、配布EXEの起動と操作、mainとタグの対象SHAの最新CIを公開前に確認します。360°回転は全26方向からの連続回転と実画面操作の両方で検査します。

[単独レビューと資料の確認範囲](https://github.com/oltotlo79-rgb/OJT/blob/v1.2.2/docs/superpowers/handoff/2026-09-22-education-review.md)に不具合と再発防止策を記録しています。別のAstraエージェントによる独立レビューではありません。

特殊接点は上記4種類の教育用模擬動作です。各機種の全特殊デバイスや実機への通信・転送には対応していません。ジェイテクトPC10Gの全特殊リレー表は未照合です。実機GPUでの60fps測定はソフトウェア描画の検査には含みません。

Windows x64向けインストーラと、EXE1個で配布できるポータブル版を用意します。
