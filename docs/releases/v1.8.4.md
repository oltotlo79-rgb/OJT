# 電気教育ツール v1.8.4

未公開候補v1.8.3で準備した改善を含むリリースです。

## 主な変更

- 起動中の画面を濃紺・ミント色と配線図のモチーフで統一しました。本体のローディングには控えめなアニメーションを加え、動きを抑える設定にも対応しました。
- ポータブル版の展開中から起動案内を表示します。本体は3D・結果画面などを必要な時点で読み込みます。長い読み込みで課題一覧のキャッシュが直ちに期限切れになる問題も修正しました。
- 3Dの押しボタンに「押し続ける」とShift＋クリックによる保持を追加しました。複数保持、保持中の別ボタン操作、個別・一括解除ができます。
- 回路点検・修復の配線両端に、回路図の線番と対応するマークチューブを追加しました。電線一覧での線番確認・検索にも対応しました。
- 取扱説明書・ヘルプのインストール章を削除し、新しい操作の説明と図を更新しました。

## 公開前の検査手順の修正

候補v1.8.3のCIで、画面表示前の即時判定により「表示・作業ファイル」を開かずに保存ボタンを待つ検査手順が見つかりました。メニューの入口が操作可能になるまで待ってクリックするよう修正し、4モードの保存・復帰検査が成功しました。制限時間や保存内容の比較条件は変更していません。

この修正による製品コードの変更は版数のみです。候補版のタグ・検査記録を保持し、v1.8.4のコミットと配布物で公開前の検査を行います。

## 配布と検証記録

内蔵課題は372題。Portable EXEとSetup EXEを配布します。ポータブル版のお渡し用フォルダは `OJT/release/v1.8.4`、検証記録は `OJT/release/verification/v1.8.4` です。

検査・ビルドは他監査の実行状態を確認し、低優先度・2論理CPU・1ワーカーで順番に実施します。製品の機能確認と起動時間の計測記録は、候補版の記録 `OJT/release/verification/v1.8.3` も参照します。
