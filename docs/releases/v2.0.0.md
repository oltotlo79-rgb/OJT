# 電気教育ツール v2.0.0

取扱説明書・ヘルプと実際の操作の食い違いを通しで点検して直し、3D図の品質（見た目と配線の正しさ）を上げ、各社PLCの仕様を実機の資料に近づけた版です。解答操作動画9本は、わざと失敗してから考えて直す場面を入れて撮り直しました。

## 主な変更

### 説明書・ヘルプと実操作の食い違い（通し点検）

- 説明書の全章を実画面で通し点検し（記録は `OJT/release/verification/v2.0.0/manual-walkthrough.md`）、食い違い33件を「画面を直す」「説明書を直す」に分けて直しました。画面側は、危険操作の警告の文言（内部の識別子が出ていた）、手順帯の「手順」の見出し、端子の札の例など。説明書側は、視点操作の早見表の場所、チャートの閉じ方、各社ツールバーの名前、設定の欄の名前など。
- 手順帯の「部品装着」は、課題の回路で使う部品（CR1・T1 など）が全部載ったときに「済」になります。在庫に予備の部品が残っていても「済」になり、案内は「CR1 をソケット S1 に載せます」のように次に載せる部品とソケットを言います。

### UI・UX

- PLCの「分割」表示で、3D盤の欄を 560×280px 以上に保ちます（1280×800 でも盤が読めます。課題・部品の欄はその下でスクロール）。
- 選んだソケットは本体を光らせず、段付きの外形の輪郭（選択＝水色の太線、ホバー＝白の細線）で示します。透明なリレーのケース越しに台座が染まる見え方を無くしました。運搬中の「ここに落とせる」は弱い緑の発光と緑の輪郭です。

### 3D図の品質

- 室内の環境マップと ACES トーンマッピングを入れ、材質を実物に寄せました（盤面の塗装、DINレールの亜鉛めっき、ニッケルめっきのネジ、黒い樹脂のソケット・端子台、PVCの電線、黄銅の圧着端子）。影の解像度も上げました。
- ネジ端子に座金と角座、圧着端子に赤い絶縁スリーブ（1.25sq）を描き、電線がスリーブの中へ入る形にしました。
- 表示灯はクロームの化粧リングとドーム形のレンズ、押ボタンは化粧リングとガード、端子台は仕切り板と両端の固定ねじ、DC24V電源は DC出力の表示LED（通電で緑）、リレー MY4N は励磁で動く機械式インジケータと型式印字、タイマ H3Y-4 は型式印字を足しました。
- 机上へ出る電線がブレーカ・電源スイッチの本体を貫いて見えていた不具合を直しました（電線の整形が避ける立体に両機器が無かった）。全PLC課題×4社と全組立・修復課題の模範配線で、電線が両機器の箱と交わらないことを検査に加えました。
- 描画の重さ: 表示灯の取付座とレンズ受け、押ボタンの取付座とガード（同じ黒い樹脂）を1つの形に結合し、端子台の固定ねじを1本のインスタンス描画にして、ドローコールの増え方を抑えました。GPU のない PC（ソフトウェア描画）では影の解像度を 2048 から 1024 に落として軽くします（GPU があるときの見た目は変わりません）。

### PLC の仕様

- タイマの時間単位を実機と同じく**命令で選ぶ**ようにしました（三菱 OUT/OUTH/OUTHS、オムロン TIM/TIMH/TMHH、ジェイテクト TMR/TMRH、シャープ TMR）。「デバイスの入力」窓に「時間単位」の選択が出て、設定値はその単位の刻みで読みます（1行入力 `OUTH T0 K50` も可）。命令語リストとグリッドは単位の命令名で書きます。以前の作業ファイル・課題（単位の無いタイマ）は三菱の番号帯（T200〜＝10ms・T256〜＝1ms）で読む互換を残しています。表記切替で切替先に無い単位は既定の単位へ寄せて設定値を丸め、知らせを出します。
- 三菱 FX5U: タイマ・カウンタの範囲を仕様表の既定 1024 点（T0〜T1023・C0〜C1023）にし、`Shift+F7` / `Shift+F8`（微分接点）の注記を「GX Works3 の割当（2次資料で確認）」にして出典 S9 を足しました。筐体は仕様表の明灰（マンセル 0.6B 7.6/0.2）に、中央の黒い前面パネルに表示灯・銘板・スイッチを載せる見た目にしました。
- オムロン CP1E-N30DR-A: 本体表示灯を W479 の 6 灯（POWER・RUN・ERR/ALM・INH・PRPHL・BKUP）にし、端子配列を W479 §3-1-3 の図どおりの上段・下段に並べ替え、出力 COM の受け持ちを 1/1/3/3/4 にしました（d-001 の模範配線は COM0〜COM2 を渡り配線します）。
- ジェイテクト: タイマ命令を TMR / TMRH にしました（以前は PCwin の OUT と仮定）。取扱説明書が未入手の前提は設定の「この見た目の根拠（指導員向け）」に残しています。

### 動画・説明書

- 解答操作動画9本を撮り直し、各本に「失敗 → 観察 → 考え方 → 修正」の場面を入れました（PB1 の b接点に配線、正常な青線を断線と指摘、変換せずにモニタ、各社で通らないデバイスの書き方、出力COMの渡りの入れ忘れ、正解のランプを点いたままに描く、停止の b接点の入れ忘れ など）。
- 説明書に図を8枚足しました（手順帯の「部品装着 済」、圧着端子と絶縁スリーブの拡大、PLC の分割表示、PLC本体の拡大 4社、タイマの時間単位）。全図を新しい画面で撮り直し、PDF を再生成しました。

## 互換性

- 以前の作業ファイル・課題ファイルはそのまま読めます。タイマの `base`（時間単位）が無いセルは三菱の旧来の番号帯で読み、動作は変わりません。
- オムロン CP1E の出力 COM の受け持ちが変わったため、CP1E の机上配線を含む以前の作業ファイルでは、COM への配線が新しい端子配列に合わない場合があります。その場合は「配線をやり直す」か、PLC への電線をつなぎ直してください。

## 今回行っていないこと

実機PLCへの接続、純正PLCソフトとの連携、利用先のPCでの起動計測、実機GPUの60fps試験は行っていません。TOYOPUC（ジェイテクト）の取扱説明書はパスワード付きで未入手のため、命令語・キー割当・ラック外観は公開資料から起こした前提のままです。
