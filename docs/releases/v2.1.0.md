# 電気教育ツール v2.1.0

取扱説明書・ヘルプと実際の操作の食い違いをもう一度通しで点検して直し、画面の重なり・見にくさを直し、PLCを実機に近づけた版です。PLCは**書き込んだプログラムで動く**ようになりました（変換しただけでは動きが変わりません）。説明書の図を増やし、解答操作動画は書込みの手順と失敗の場面を入れて撮り直しました。

## 主な変更

### PLC を実機に近づける

- **PLC は書き込んだプログラムで動きます。** 「変換」はラダーの誤りを調べるだけになり、PLC へ送るのは「書込み」（三菱「シーケンサへの書込み」・オムロン「転送［PC → PLC］」・シャープ「PLCへの書込み」・ジェイテクト「PCへ書込み」〔資料未入手のため仮の名前〕）です。運転中（RUN）の書込みは「STOPして書き込む」を確かめてから行い、プログラムの無い PLC は RUN にならず ERR の表示灯が点きます。
- 手順の帯に「書込み」の段と、「PLCのプログラム: 書込み済み／エディタと違う／なし」の札を足しました。判定・PLC実験・見直し・作業の再開も PLC に書き込んだプログラムで行い、書き込んでいない変更があれば判定の前に「書き込んでから判定」「このまま判定」を選べます。作業ファイルは PLC のプログラムも保存します（以前のファイルは変換済みなら書込み済みとして開きます）。
- PLC 本体の表示灯は、壁コンセントから給電されているときだけ点き、入出力の表示灯は実際の入出力を映します（モニタの有無に関係なく）。電源が来ていない PLC は動かず、札は「PLC: 電源なし」になります。
- モニタ中、タイマ・カウンタの現在値を回路ブロックの見出しの右に「T0 現在値 12（設定 K30）」の形で出します。三菱は加算式、オムロン・シャープは資料どおり減算式（設定値から0へ）です。
- 説明書の命令表記の表を方言のデータと照合するテストを足し、ジェイテクトのタイマを「TMR・TMRH」に直しました。

### 画面の重なり・見にくさ

- 自動保存の表示を下の帯へ移し、右の欄のボタンに重ならないようにしました。
- 3D の視野角を 24° にして奥行きのゆがみを減らし、ビューキューブを避けて盤・PLC を収めます（キューブは常に左上。高さ 360px 未満の画面では出しません）。
- PLC の銘板を本体の面に描き、機器の名札が機器に重ならないようにしました。「3Dの名札を表示」で名札を消せます。
- PLC の右の欄を 260px に広げ、I/O割付の表が切れないようにしました。狭い窓でも並べて・分割の 3D とエディタ・ラダーが使える高さを保ちます。
- 回路点検の指摘の小窓は押した場所の近くに出ます。1280×800 でデバイスを入力している間も、置くマスと入力欄が両方見えます。PLC の手順の帯は2段に固定し、札の文字が変わっても 3D の画面がずれません。

### 説明書・ヘルプ・動画

- 説明書の図を 88 枚から 116 枚に増やし、全部を新しい画面で撮り直しました。章の始めに「この章でできること」、手順のある章に「うまくいかないとき」を足しました。
- 解答操作動画を撮り直し、PLC の動画に書込みの手順と失敗の場面（三菱: 直したあとの書込み忘れ、オムロン・ジェイテクト・シャープ: 書き込む前の RUN）を入れました。

## 検証記録

記録は `OJT/release/verification/v2.1.0`、ポータブル版のお渡し用フォルダは `OJT/release/v2.1.0` です。お渡し用フォルダにはPortable EXEを1つだけ置きます。GitHub ReleaseにはPortable EXEとSetup EXEを添付します。

## 互換性

- 以前の作業ファイル・課題ファイルはそのまま読めます。PLC のプログラムを持たない以前の作業ファイルは、変換済みならそのラダーを書込み済みとして開きます（動きは以前と同じです）。

## 今回行っていないこと

実機PLCへの接続、純正PLCソフトとの連携、利用先のPCでの起動計測、実機GPUの60fps試験は行っていません。TOYOPUC（ジェイテクト）の取扱説明書はパスワード付きで未入手のため、命令語・キー割当・書込みの名前・現在値の数え方は公開資料から起こした前提のままです。
