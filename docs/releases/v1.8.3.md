# 電気教育ツール v1.8.3

この候補は未公開です。画面操作検査の手順修正を含め、v1.8.4として公開します。

## 起動の待ち時間と表示

- ポータブル版の展開方法を変更し、大きな中間アーカイブの一時コピーを省きました。
- ポータブル版は本体の展開中から起動案内を表示します。本体では3Dなどの読み込み前にローディング画面を出します。
- ホームで使用しない3D画面・結果画面・メイン処理の一部は、最初に使用するときに読み込みます。
- 課題一覧の読み込みに3秒以上かかった場合、一覧を返した直後にも全件を読み直していた不具合を修正しました。同時の読み込み要求も1回にまとめます。
- 画面の読み込みが失敗した場合は再読み込みできます。起動中でもウィンドウを閉じられます。編集開始後の終了時は従来どおり保存を確認します。
- 起動時間の実測条件と結果は検証記録に保存します。Windowsが実行を開始する前の検査や確認画面の時間は短縮対象に含みません。

## 押しボタンを同時に操作

- 3D図の下の「押し続ける」で、1個以上のボタンを保持できます。保持中に別の3Dボタンを操作できます。
- 3DボタンのShift＋クリックでも保持・解除できます。もう一度押すと個別解除、「すべて離す」またはEscで一括解除します。
- 通常の押下中は、ポインターがボタンの外へ移動してもマウスを離すまで押下を保ちます。
- 「押下中」には演算側の実際の押下状態を表示します。別アプリへの切替、課題切替、配線・部品編集、判定・再生開始では保持を解除します。
- 回路組立・部品点検・回路点検修復・PLCの3D図で共通の操作です。

## 回路図と対応するマークチューブ

- 回路点検・修復の配線両端に、番号を印字した白いチューブを表示します。回路図の引出線と電線一覧にも同じ線番を表示します。
- Pはプラス母線、Nは0V母線、01・02…は途中の接続です。同じ接続から分岐する配線は同じ番号です。
- 既設線の印字は故障前の回路を基準にするため、誤配線・断線によって変わりません。修復で追加した白線は始点側、始点に線番がなければ終点側の線番を表示します。
- 短い渡り線はチューブの長さを合わせ、各端から経路の半分以内へ配置します。角や端子ネジへ重ねないようにしています。
- 電線一覧の自分用の線番・注記は、回路図に対応するチューブの印字と区別して説明しています。
