## 概要

Phase 1〜6 の全機能を収めた最初の正式版。有接点シーケンス回路の組立・点検・修復と、
4メーカーのPLCラダー、回路図エディタ、アプリ内ヘルプとPDF取扱説明書を同梱している。

- **モード B（回路組立）**: 部品を配線して有接点シーケンス回路を組み立てる練習課題。
- **モード C1（部品点検）**: テスタで部品単体（コイル・接点など）の良否を判定する課題。
- **モード C2（回路点検・修復）**: 通電状態の回路から故障箇所をテスタで特定し、白線で
  修復する課題。故障の指摘は活線での直流電圧測定（DCV）で診断する。
- **モード D（PLCラダー）**: 三菱電機（MELSEC iQ-F）・オムロン・ジェイテクト・シャープの
  4メーカーのスキンと3D外観を持つPLCで、入出力配線とラダープログラムを作成する課題。
  画面・キー割当・命令表記がメーカーごとに切り替わる。
- **回路図エディタ**: 有接点シーケンス回路をシーケンス図として描き、机上で検算してから
  3D盤へ配線ガイドに従って配線できる。回路図の要素をクリックすると3D盤の対応する端子が
  光る（逆方向も可）。
- **ヘルプ（取扱説明書）**: アプリ内の引き出しで取扱説明書を読める。`F1` でいつでも開き、
  「言葉で探す」で本文を検索できる。全13章。
- **PDF取扱説明書**: 同じ取扱説明書を PDF でも同梱している（A4・全67ページ・図17枚）。
  ヘルプの「説明書（PDF）を開く」で OS の既定ビューアが開く（インストール先の
  `resources/manual.pdf`）。
- **画面品質の機械点検（UI監査）**: 1280×800 / 1440×900 / 1920×1080 の3種の窓幅で全画面を
  歩き、はみ出し・文字切れ・重なり・小さすぎる文字や的を機械的に数える E2E を備える。

## 動作環境

- Windows 10 / 11（x64）
- コード署名なし（unsigned）
- 完全オフラインで動作する（起動時・実行時ともに外部へ通信しない。自動更新も無い）

## インストール

配布物は次の2種類。用途に応じて使い分けること。

- **`電気教育ツール-1.0.0-x64.exe`（NSIS インストーラー）**: 通常のインストール用。実行すると
  スタートメニュー登録などを伴ってインストールされる。管理者権限は不要。個人利用・複数端末
  への展開に向く。
- **`電気教育ツール-1.0.0-x64.zip`（ポータブル版）**: 展開するだけで実行できる。管理者権限が
  無い環境や、インストールせず一時的に試す場合に向く。

### 初回起動時の注意（SmartScreen）

このビルドは**コード署名をしていない**ため、初回起動時に Windows SmartScreen の警告
（「Windows によって PC が保護されました」）が表示されることがある。「詳細情報」→
「実行」を選択して起動すること。インストーラーの説明画面にも同じ手順を掲載している。

### オフラインでの利用

インストールにも実行にもネットワークは要らない。インストーラー（またはポータブル版の zip）を
USB メモリなどで運び、ネットワークから切り離した端末で展開・実行できる。自動更新の仕組みは
持たないので、版を上げるときは新しい配布物を配り直す。

## 未実施の確認

リリース手順チェックリストのうち、**次の2つはこの環境では実施できていない**。
実機と別端末が要るため、配布先で確認すること。

  本リリースの検証環境ではソフトウェア描画（SwiftShader）で E2E を回しており、
  GPU描画での実測値は取れていない。実機で

  （§16 Phase 5 受入基準④）。
- **7. オフラインの Windows 11 への NSIS インストールと課題の完走 — 未実施**。
  ネットワークアダプタを無効にした別端末でインストーラから導入し、課題を1つ最後まで

  なお、アプリが通信しないこと自体は E2E（オフライン検査）で確認済みで、

## 既知の制限

- **画面品質の機械点検の残件**: 最終の全E2E（2回とも同じ）で残った指摘は合計 **25件**
  （**小さすぎる文字 24件**、**折り返し 1件**）で、**先へ進めなくなる指摘（blocking）は 0件**。
  はみ出し・文字切れ・3D盤の名札の重なり・的の小ささ・フォーカス落ちは **0件**。
  残件の内訳は 1920×1080 に 14件、1440×900 に 7件、1280×800 に 4件で、
  モードBの「並べて」「回路図」表示とモードC2の指摘まわりに集まっている。
- **モードC1の危険操作の帯**: 機械点検の巡回では危険操作の帯を出せない経路があり、
  その画面だけ点検の対象外になっている（注記として記録済み）。
- **取扱説明書の図の吹き出し**: ビューキューブの図のように置き場所が狭い図では、
  丸数字が隣の枠線にかかることがある（枠線は細いので中の文字は読める）。
  吹き出しがアプリの文字に乗らないことは17枚すべてで機械的に確認している。
- **性能数値**: ソフトウェア描画（GPU非依存のレンダリング経路）での性能数値は実機（GPU描画）
  より重くなる傾向がある。参考値であり、実利用環境での体感性能とは異なる場合がある。
- **OSダイアログ**: 実物の OS ダイアログ（保存／読込）の自動テストは、固定パスへの差し替えに
  よる IPC 往復確認に留まる。
- **その他の積み残し**: 命令語リストの印刷用レイアウト未実装（§10.7）、3D分割ビューでの
  ボード縮小、SwiftShader での初回フレーム遅延、疑い一覧が5件表示のとき折り返しの外へ
  出ること。いずれも致命ではない。
