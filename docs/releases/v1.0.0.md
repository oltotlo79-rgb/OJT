# 電気教育ツール v1.0.0 リリースノート

## 概要

Phase 1〜5（モード B・C1・C2・D、回路図エディタ）を実装したリリース。

- **モード B（回路組立）**: 部品を配線して有接点シーケンス回路を組み立てる練習課題。
- **モード C1（部品点検）**: テスタで部品単体（抵抗・コイルなど）の良否を判定する課題。
- **モード C2（回路点検・修復）**: 通電状態の回路から故障箇所をテスタで特定し、白線で
  修復する課題。
- **モード D（PLCラダー）**: 三菱電機（MELSEC iQ-F）・オムロン・ジェイテクト・シャープの
  4メーカーのスキンと3D外観を持つPLCで、入出力配線とラダープログラムを作成する課題。
- **回路図エディタ**: 有接点シーケンス回路をシーケンス図として描き、机上で検算してから
  3D盤へ配線ガイドに従って配線できる。回路図の要素をクリックすると3D盤の対応する端子が
  光る（逆方向も可）。

**本リリースの後、ヘルプとPDFマニュアルを追加する Phase 6 を計画中であり、それを経てから
実際の公開を行う。v1.0.0 は最終版ではない。**

## 動作環境

- Windows 10 / 11（x64）
- コード署名なし（unsigned）
- 完全オフラインで動作する（起動時・実行時ともに外部へ通信しない。自動更新も無い）

## インストール

配布物は次の2種類。用途に応じて使い分けること。

- **`電気教育ツール-1.0.0-x64.exe`（NSIS インストーラー）**: 通常のインストール用。実行すると
  スタートメニュー登録などを伴ってインストールされる。管理者権限は不要。個人利用・複数端末
  への展開に向く。
- **`電気教育ツール-1.0.0-x64.zip`（ポータブル版）**: 展開するだけで実行できる。管理者権限が
  無い環境や、インストールせず一時的に試す場合に向く。

### 初回起動時の注意（SmartScreen）

このビルドは**コード署名をしていない**ため、初回起動時に Windows SmartScreen の警告
（「Windows によって PC が保護されました」）が表示されることがある。「詳細情報」→
「実行」を選択して起動すること。インストーラーの説明画面（`apps/desktop/build/license.txt`）
にも同じ手順を掲載している。

## 内蔵課題

内蔵課題は合計 **28題**を同梱している。

| モード | 件数 |
|---|---:|
| B（回路組立・assemble） | 8 |
| C1（部品点検・inspect-parts） | 4 |
| C2（回路点検・修復・inspect-repair） | 8 |
| D（PLCラダー・plc） | 8 |

## 既知の制限

- ソフトウェア描画（GPU非依存のレンダリング経路）での性能数値は実機（GPU描画）より重くなる
  傾向がある。参考値であり、実利用環境での体感性能とは異なる場合がある。
- 実物の OS ダイアログ（保存／読込）の自動テストは、固定パスへの差し替えによる IPC 往復確認に
  留まる。

## リリース手順チェックリスト

**公開は利用者の明示の指示を受けてから行う。** 以下の 1〜8 は指示が無くても進めてよい準備で、
9 以降は指示を受けてから実行する。

- [ ] 1. `git pull --rebase origin main` して main が最新であること
- [ ] 2. `pnpm -r test` が全て通ること
- [ ] 3. `pnpm -r typecheck` と `pnpm lint` が無警告で通ること
- [ ] 4. `pnpm --filter @ojt/desktop build` と `pnpm --filter @ojt/desktop e2e` が全て通ること（2回連続）
- [ ] 5. `pnpm --filter @ojt/desktop dist` が成功し、`release/artifacts.md` が生成されること
- [ ] 6. **実機（内蔵GPU・FHD 1920×1080）** で `release/win-unpacked/電気教育ツール.exe` を起動し、
      PowerShell で `$env:OJT_PERF_TARGET='1'; pnpm --filter @ojt/desktop e2e perf` を走らせて
      測定値が **60fps 以上**であること（§16 Phase 5 受入基準④。測定値をこのチェックリストの下に転記する）。
      本プロジェクトの開発環境は Windows + PowerShell なので、`VAR=value cmd` の形は使えない
      （`$env:` で立ててから `;` で続ける）
- [ ] 7. **オフラインのWindows 11** でNSISインストーラからインストールし、課題を1つ最後まで
      完了できること（§16 Phase 5 受入基準③）。ネットワークアダプタを無効にして確認する
- [ ] 8. ポータブル版（zip）を展開して起動できること
- [ ] 9. （指示後）`git tag -a v1.0.0 -m "電気教育ツール v1.0.0"` と `git push origin v1.0.0`
- [ ] 10.（指示後）GitHub Release を作り、本節の「GitHub Release 本文」を貼り、
      `release/` の2ファイルを添付する
