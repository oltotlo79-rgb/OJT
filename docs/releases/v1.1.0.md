# 電気教育ツール v1.1.0

公開先: https://github.com/oltotlo79-rgb/OJT/releases/tag/v1.1.0

## 使いやすさの改善

1. 3D盤のブレーカとスイッチを直接押して電源を操作できます。
2. 部品をパレットからソケットへ運び、端子間をドラッグして配線できます。中断・取り外しも整理しました。
3. テスターの測定先と現在の操作を見やすくし、3D端子と測定の導線を揃えました。
4. 常設ボタンを整理して盤とラダーの作業面を広げ、文字切れ・不自然な改行・重なりを修正しました。
5. 文字倍率・高コントラスト・キーボード操作を整え、押せない操作には理由を表示します。
6. 初回の5段階ガイドが実操作に合わせて進み、設定やヘルプから再開できます。
7. PLC画面の配置、キー、メニュー、記号入力の順をメーカー別に改めました。確認範囲は下記のとおりです。
8. 内蔵課題を72題へ拡充し、級・難易度・検索から選びやすくしました。
9. 結果から作業を保って戻り、操作を順に見直し、模範と自分の波形を比較できます。
10. 今回の結果を1枚のPDFまたは単独HTMLへ保存できます。アプリには成績履歴を残しません。
11. ヘルプと説明書を刷新しました。4モードの通し練習40手順、15機能の説明、72題の索引、40枚の実画面図を収録しています。
12. ポータブル版をEXE1個に集約しました。インストーラの日本語表示と配布物の欠落検査も改善しました。

## PLCの確認範囲

GX Works3、CX-Programmer Classic、JW-300SPは公式マニュアルの画面と操作表を照合しました。PCwinの画面構成は公式カタログで確認しましたが、操作マニュアルは認証が必要で専用キーを確認できていません。未確認のキーに他社の操作を流用せず、記号ボタン・右クリック・ダブルクリックから編集できます。

実PLCへの接続・通信設定など純正ソフトの全機能を実装した製品ではありません。色の数値やピクセル寸法の完全一致も保証しません。詳細は[メーカー資料と確認範囲](https://github.com/oltotlo79-rgb/OJT/blob/v1.1.0/docs/reference/ladder-skin-sources.md)を参照してください。
