# 電気教育ツール v1.1.1

v1.1.0公開後に発生したCI失敗を修正し、検証と公開の手順を強化した版です。アプリの操作・課題内容はv1.1.0を引き継ぎます。

## 修正内容

- 保存テストが外部プロセスの実行速度に依存していた問題を修正。実際のファイルロックで最初の置換失敗を発生させ、再試行時には解放完了を確認します。保持が続くときの打切り・元データの保護・一時ファイルの除去も検査します。製品の保存制限時間は変更していません。
- 画面撮影時の一時的な`UnknownVizError`に限り、撮影のみ最大2回待ち直します。操作・判定のテスト全体の自動再実行は廃止し、初回失敗のトレースを保存します。
- 公開コマンドに必須検査を追加。公開対象SHAのmainとタグの最新CIが両方成功し、添付EXEのSHA256が検証済みファイルと一致する場合だけ、下書きを正式公開します。古いコミットの成功を根拠に公開できません。

## レビューの位置づけ

v1.1.0の追加レビューでは重要7件・軽微5件を修正し、回帰テストと実画面検証を実施しました。[レビュー記録](https://github.com/oltotlo79-rgb/OJT/blob/main/docs/superpowers/handoff/2026-09-22-final-ui-review.md)を参照してください。「Astra視点」は単独での再点検を指し、別のAstraエージェントによる独立レビューではありません。サブエージェントは使用していません。

PLCの確認範囲・UI改善・残る対象外機能は[v1.1.0の記録](https://github.com/oltotlo79-rgb/OJT/releases/tag/v1.1.0)と同じです。
