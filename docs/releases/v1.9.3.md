# 電気教育ツール v1.9.3

回路点検・修復の個別配線復元・指摘変更、操作ログの初期折りたたみ、3D電線の描画改善、起動案内の前面保持を含む公開版です。v1.9.2は最終CIで検査の想定に問題が見つかったため、一般公開していません。既存タグは変更せず、新しい版で確認します。

## 変更と確認方法

- 回路点検・修復の「外した青線」に「元に戻す」を追加し、開始時の端子・線色・線番・故障状態を復元します。指摘一覧の「変更」から種類や部品不良の内容を選び直せます。
- 全4モードの操作ログと経過時間を初期状態で折りたたみ、3D図を広く表示します。閉じている間も記録と計測は続きます。3D電線の断面を細かくし、曲面を滑らかにしました。
- ポータブル版の起動案内を展開前に表示し、本体が表示され、実際の描画内容を確認するまで手前に保持します。Windowsが実行を始める前の待ち時間はPC環境に依存します。
- 動画7本はこの画面に合わせて収録済みです。作業前の課題文・タイムチャート等の赤い強調、最初の作業の説明、ログの開閉を示します。修復では指摘変更と青線の個別復元も実演します。操作の待ち時間を15%延ばし、再生速度0.5・0.75・1・1.25・1.5倍を利用できます。
- 説明書とヘルプの復元・指摘変更・ログの開閉、タイムチャートの位置、PLC書き出しの案内を実際の操作に合わせました。
- ログの開閉検査を修正しました。動作中の遅延通知は正常に追記・集約更新されるため、操作履歴を行ごとに確認し、閉じている間の新しい操作も記録されることを確認します。警告の停止や検査の自動再試行は行いません。

v1.9.2のCIでは、開始とブレーカONのログは保持され、処理の遅れを示す警告が正しく追加されていました。検査が全体の完全一致を要求したため失敗しました。失敗の記録は保持し、検査コードを修正して新版の全検証を実施します。

公開には、固定lockfileのインストール、型検査・lint・全体テスト、内蔵課題検証、2回連続の標準画面操作検査、配布EXEの操作・起動・同梱PDFと動画の照合、mainとタグの対象SHAの最新CI成功が必要です。記録は `OJT/release/verification/v1.9.3` に置きます。お渡し用 `OJT/release/v1.9.3` にはPortable EXEを1つだけ置きます。

## 残る警告・検証範囲

Three.jsのClock・影方式、CommonJS、Nodeの型変換、SwiftShaderのGPU待機、色出力指定の警告は残ります。electron-vite 5.0.0のpeer条件とVite 8.3.0の組み合わせ、非推奨の下位依存、ビルダーの説明・作者メタデータ、pnpm検出、workspaceの重複参照の警告も記録します。依存バージョンは変更せず、固定lockfileと必要な検証を行います。配布EXEは未署名です。

利用先PCの起動時間、実機GPUの60fps、実機PLC接続、純正PLCソフトとの連携は検証していません。動画は実操作の検査・説明と操作と完了の代表フレームを確認する方法で、全フレームの目視ではありません。起動はウィンドウ採取と実描画の画像確認で、デスクトップ全フレームや全PCでのクリック直後の表示を保証するものではありません。
