# 電気教育ツール v1.8.1

## 修正

- PLCで結果から作業へ戻ったとき、変換済みラダーとテスターの状態を読み直します。電源OFF・CPUのSTOPから再開できます。
- メーカーを切り替えても、保持する配線の線番・注記・経路、測定記録・診断メモ・ウォッチと学習記録を残します。外れる線とプローブは切替前に説明します。
- チェックした電線を単独削除した後でも、残った電線を一括削除できます。編集対象と一括削除の対象数を表示します。
- 点検修復の追加線・削除線の一覧から、該当する線や元の端子へ移動できます。
- 点検修復では正常部品の交換も記録し、取消・保存・復元に対応します。交換前の故障の有無によってボタンの反応を変えません。
- 判定結果・見直し中の通常終了でも、元の作業を自動保存します。
- 保存内に課題定義がある作業は、現在の課題一覧に定義がなくてもホームから再開できます。
- 「復元しない」で一時保存を破棄した後は、ホームの再開表示も更新します。
- 操作動画のメーカーを切り替えても、再生速度の選択を反映します。
- プローブキー、エラー復旧、PLCの停止条件解除について、説明書を現行操作に揃えました。

## 操作の改善

- 診断メモを編集・削除でき、関連する測定記録を保持します。
- 保存破棄・課題切替・復元の確認をモーダルに揃え、背景のキー操作を抑止します。取消後は元のフォーカスへ戻ります。
- 広い画面でも「表示・作業ファイル」の操作をまとめ、主要操作の位置を揃えます。
- 課題検索は全角・半角と複数語に対応します。
- PLCの測定にもb/r/0/Escキーを追加し、次に置くプローブを表示します。
- ラダー画面に、この練習での変換・書込み・RUNの違いを表示します。
