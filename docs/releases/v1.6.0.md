# 電気教育ツール v1.6.0

## 作業と下書きの保護

- 一覧で同じ課題を選び直したときに作業が初期化される不具合を修正しました。ホームと一覧の「続きから再開」で、現在の配線・解答・測定記録・履歴へ戻れます。
- 別の課題への移動と明示的なやり直しには、保存・保存せず進む・取消の確認を追加しました。保存の取消や失敗では現在の作業を保持します。
- 課題作成の下書きを自動保存し、画面移動と次回起動で復元します。不完全なJSONも保存できます。通常終了は練習作業と下書きの保存完了を待ちます。

## 課題作成と使いやすさ

- 回路組立・回路点検修復の模範回路図と、PLCの模範ラダーを画面上で編集できるようになりました。記号入力、Undo/Redo、編集の取消、模範動作の検証を利用できます。
- 作図中の変更も下書きへ保存します。検証に合格した課題は「検証してJSONを保存」で配布できます。
- 課題一覧の検索語・級・難しさ・テーマを、起動中は練習の種類ごとに保持します。「絞り込みをリセット」を追加しました。
- 動画のボタンに基本例題の番号を表示しました。選択中の課題と動画の題材を、再生前に区別できます。
- ヘルプとPDFの設定・保存・課題作成手順を更新しました。
- シミュレーション異常時に詳細を取得できない場合も復帰手順を表示し、停止した状態で判定を開始しないようにしました。

## 継続して利用できる内容

324課題（回路組立90、部品点検54、回路点検・修復90、PLC90）と、4種類の実操作動画を同梱しています。Windows x64のインストーラ版と、EXE1個のポータブル版を配布します。旧作業ファイルの読込にも対応します。

課題下書きと配布用JSONは別に保存します。強制終了や電源断では最後に保存を完了した状態まで復元できます。実PLCとの通信、ACV測定、ワード演算は引き続き未対応です。

変更箇所・検証結果は[レビュー対応記録](https://github.com/oltotlo79-rgb/OJT/blob/v1.6.0/docs/review-response-2026-09-24.md)に記載しています。
