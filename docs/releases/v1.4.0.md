# 電気教育ツール v1.4.0

組立・PLCを配線ゼロから開始するように変更し、電源端子・ブレーカー・電源スイッチの3Dモデルを作り直しました。組立中にも端子を直接選んで測定できます。

## 3Dの見た目

- 左のDC24V出力部に絶縁壁、金属の接触板・座金、P＋24V／N−0Vの銘板を追加しました。端子を覆っていた部品を取り除き、配線はネジから左側へ見える状態で引き出します。
- ブレーカーは2極の段差付きケース、低い端子カバー、滑り止めのある連動レバーに変更しました。
- 電源スイッチは大きな揺動式の操作部にI／Oを刻み、ブレーカーと形状を区別しました。機器名の横には「入 ON」「切 OFF」を表示します。
- 電源機器と重なっていた状態表示を3Dキャンバスの外へ移しました。

## 配線・測定と作業の進め方

- 組立60課題・PLC60課題には、点検用の電線3本を追加しません。部品点検のチェック回路と故障修復の点検対象回路は、それぞれの課題に必要な状態で開始します。旧版の作業ファイルは保存された配線をそのまま復元します。
- 組立画面の「測定」でテスターを表示し、3Dの端子を黒・赤の順に選んで測定できます。下部の小さな操作帯でプローブを選び直し、測定値を確認し、「両方外す」で解除できます。
- 空白をクリックしてもプローブは外れません。B／Rで黒・赤を選択、Escで両方を外します。測定設定とプローブも作業ファイルに保存します。
- 配線の接続先を選んでいる間は、その場で「取消」を押せます。操作帯の高さをそろえ、配線開始や測定切替で端子の位置がずれないようにしました。
- 手順欄から目的の道具へ移動できます。配線・測定・回答・修復の順番を固定せず、行った作業を個別に表示します。
- PLCの利用者課題ではPB4も入力に割り付けられます。

初期配線、P端子の出線経路、満杯端子の測定、測定状態の保存復元、実際のマウスによる配線・測定を回帰検査に追加しました。説明書の図も新しい画面で撮り直しています。
