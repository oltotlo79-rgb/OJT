# 電気教育ツール v0.2.0 リリースノート

## 概要

Phase 1（モード B: 回路組立）と Phase 2（モード C: 回路点検・修復）を実装したリリース。

- **モード B（回路組立）**: 部品を配線して回路を組み立てる練習課題。
- **モード C1（部品点検）**: テスタで部品単体（抵抗・コイルなど）の良否を判定する課題。
- **モード C2（回路点検・修復）**: 通電状態の回路から故障箇所をテスタで特定し、白線で修復する課題。

内蔵課題は **28題**（assemble 8 / inspect-parts 4 / inspect-repair 8 / plc 8）を同梱しているが、
このうち **PLC（モード D）8題はデータの同梱のみで、デスクトップアプリ側に対応 UI がまだ無い**。
詳細は「既知の制限」を参照。

## 動作環境

- **Windows 10 / 11（x64）**
- コード署名なし（unsigned）

## インストール

配布物は次の2種類。用途に応じて使い分けること。

- **`電気教育ツール-0.2.0-x64.exe`（NSIS インストーラー）**: 通常のインストール用。実行すると
  スタートメニュー登録などを伴ってインストールされる。個人利用・複数端末への展開に向く。
- **`電気教育ツール-0.2.0-x64.zip`（ポータブル版）**: 展開するだけで実行できる。管理者権限が
  無い環境や、インストールせず一時的に試す場合に向く。

### 初回起動時の注意（SmartScreen）

このビルドは**コード署名をしていない**ため、初回起動時に Windows SmartScreen の警告
（「Windows によって PC が保護されました」）が表示されることがある。「詳細情報」→
「実行」を選択して起動すること。社内配布時はこの手順を利用者に案内する。

## 既知の制限

- 課題一覧の絞り込みで「**すべて**」を選ぶと、モード D（PLC）の8題（d-001〜d-008）が一覧に
  表示され、「開く」ボタンが押せてしまう。押すと「**課題が選ばれていません。**」というメッセージと
  「課題一覧へ」ボタンのみの画面に遷移し、そこで行き止まりになる（クラッシュや白画面にはならず、
  一覧へ戻る導線はある）。モード D 用のセッション画面がまだ実装されていないため。
  **Plan 3B で対応予定**（モードDのUI実装、またはそれまで一覧からモードDを隠す）。
- ソフトウェア描画（GPU非依存のレンダリング経路）での性能数値は実機（GPU描画）より重くなる
  傾向がある。参考値であり、実利用環境での体感性能とは異なる場合がある。
- 実物の OS ダイアログ（保存／読込）の自動テストは、固定パスへの差し替えによる IPC 往復確認に
  留まる。
