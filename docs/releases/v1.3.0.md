# 電気教育ツール v1.3.0

3D盤の操作を整理し、各モードの課題を3倍に拡充しました。ヒントの開閉、PLC配線画面への移動、部品の選び直しも改善しました。

## 操作の変更

- **盤面の左・中・右ドラッグは平行移動**です。端子や部品の上からでも、角度を保って動かせます。回転はビューキューブ、拡大・縮小はホイールを使います。
- 配線は端子を2つ順にクリックするか、Altを押しながら端子間をドラッグします。装着済み部品のドラッグ取り外しもAltを併用します。パレットからの装着操作はそのまま使えます。
- キューブは上下左右360°回転できます。表示を小さくし、背景の透過率を上げ、盤面を覆う範囲を減らしました。
- ヒントは上部ボタンで開閉し、パネル内の「次のヒント」で段階を進めます。「ヒントを閉じる」・Esc・外側のクリックでも閉じられます。開き直しても利用段数は増えません。
- PLCの手順にある「配線（3D盤）」「ラダー作成」を押すと、それぞれの画面へ移動できます。編集中の回路は保持されます。
- 部品カードに「ソケット一覧へ」を追加しました。

| 回路組立 | 20 | 60 |
| 部品点検 | 12 | 36 |
| 回路点検・修復 | 20 | 60 |
| PLC | 20 | 60 |
| 合計 | 72 | 216 |

許可・禁止条件、排他・一致・多数決、時間条件、短押し後の再計時、接点群ごとの点検、コイル・接点の故障診断を追加しました。PLCでは同じ条件をラダーで構成し、入力表示や特殊接点による点滅も確認します。

リレーは透明ケース内の銅線コイル・鉄心・接点を描き、励磁に合わせて接点を動かします。タイマはケース・側面の通気部・目盛・印字を改善し、盤には傾斜した筐体、金属縁、脚を追加しました。

説明書とヘルプの「目次」「見方」「選ぶ」「載せる」「壊れた」などを自然な漢字表記に統一しました。新しい操作手順と課題索引も反映しています。
