# 用語集

## この章の使い方

この説明書では、電気の仕事でよく使う言葉をできるだけやさしい言い方に直して書いています。それでも出てくる言葉は、初めて出てきたところで短く説明し、この章にまとめてあります。分からない言葉が出てきたら、ここを見てください。

ヘルプの検索欄に言葉を入れると、その言葉が出てくる節が一覧に出ます。一覧の行を押すと、その節へ跳びます。

## 用語集

| 言葉 | やさしい言い方 | 説明 |
|---|---|---|
| a接点 | ａせってん | 通常は切れていて、部品が動くとつながる接点です。⑤〜⑧の端子番号が使われます。 |
| コイル | でんじしゃく | 電気を流すと磁石になって、接点を動かす部品です。リレーやタイマの中に入っています。 |
| コイル断線 | コイルの中の電線切れ | コイルの中の電線が切れてしまった壊れ方です。コイル抵抗が測れなくなります（OL）。 |
| 自己保持 | 押した状態を覚える回路 | 押しボタンから指を離しても、そのままの状態が続く回路のつなぎ方です。 |
| タイムチャート | 信号の記録グラフ | どの信号がいつオンになったかを、横に時間を取って並べた図です。 |
| b接点 | ｂせってん | 通常つながっていて、部品が動くと切れる接点です。①〜④の端子番号が使われます。 |
| 母線 | 電気を配る大もとの線 | 電源の＋と−から、盤の中の全部の部品へ電気を配る大元の線です。 |
| 溶着 | くっついて離れない | 接点がくっついたまま離れなくなった壊れ方です。同じ組のもう一方の接点も動かなくなります。 |
| ラダー図 | プログラムの回路図 | 電気の回路図に似た形で、PLCの動きを書き表すプログラムです。 |
| レアショート | コイルの中の弱いショート | コイルの中で電線どうしが少しだけ触れて、抵抗が下がってしまった壊れ方です。 |
| 励磁 | 電気を流して磁石にする | 部品に電気を流して、内部を磁石にして接点を動かすことです。 |
