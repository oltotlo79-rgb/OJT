# 用語集

## この章の使い方

読み方・意味・操作例を分けてまとめています。ヘルプの検索では「PLC 電源」のように空白で複数の言葉を入れると、すべての言葉を含む節を探せます。

## 用語集

| 用語 | 読み | 意味 | 本アプリでの例 |
|---|---|---|---|
| a接点 | エーせってん | 操作していないときは開き、押下や励磁で閉じる接点 | リレーの⑨（COM）と⑤ |
| b接点 | ビーせってん | 操作していないときは閉じ、押下や励磁で開く接点 | リレーの⑨（COM）と① |
| コイル | コイル | 電気を流すと磁力を生じ、接点を動かす巻線 | ⑭が＋、⑬が− |
| コイル断線 | コイルだんせん | コイルの巻線が途中で切れて、電流が流れなくなる故障 | 無通電で抵抗を測るとOL |
| 自己保持 | じこほじ | 押しボタンを離しても接点を使って動作を続ける回路 | 起動ボタンとリレーのa接点を並列につなぐ |
| タイムチャート | タイムチャート | 各信号がON・OFFになる時刻と継続時間を並べた図 | 押ボタンを離した後のランプを読む |
| 母線 | ぼせん | 複数の回路が共通して電源を受け取るための配電用の線 | Pが＋24V、Nが0V |
| 励磁 | れいじ | コイルに電流を流して磁力を生じさせること | リレーが吸引して接点が切り替わる |
| レアショート | レアショート | コイルの巻線の一部が短絡して抵抗が低下する故障 | 本アプリでは正常約650Ωに対して約552Ω以下で判別 |
| 溶着 | ようちゃく | 接点が熱などでくっつき、操作しても離れなくなる故障 | a接点の溶着では非励磁でもa接点が導通 |
| ラダー図 | ラダーず | 接点と出力を梯子状に並べるPLCプログラム | X0でY0をONにする回路 |
| PLC | ピーエルシー | 入力を読み、プログラムに従って出力を制御する装置 | 入力Xから中継リレーを駆動 |
| I/O | アイオー | 入力（Input）と出力（Output） | 押ボタンが入力、リレーへの指令が出力 |
| COM | コモン | 複数の接点や入出力が共有する端子 | 入力COMの接続先は入力方式で変わる |
| シンク入力 | シンクにゅうりょく | 本アプリでは入力COMを＋側、押ボタン側を0Vへつなぐ方式 | I/O表に示すCOMとNを確認 |
| ソース入力 | ソースにゅうりょく | 本アプリでは入力COMを0V側、押ボタン側を＋へつなぐ方式 | I/O表に示すCOMとPを確認 |
| OL | オーバーレンジ | 測定範囲を超えている表示。抵抗では断線なども含む | 0Ωと読み違えず、レンジと接続を確認 |
| スキャン | スキャン | PLCの入力読込・演算・出力更新の1周期 | 本アプリの1スキャンは10ms |
| ウォッチ | ウォッチ | 指定したデバイスの値をまとめて見る機能 | X0・M0・Y0を登録して比較 |
