# 困ったときは

## こう表示されたら

画面に出た言葉をそのまま探してください。左の列がアプリの出す言葉、右の列がそのときにすることです。操作が済んだことなどは、画面の下に出る短い知らせで数秒だけ伝えられます。読み落としても、やり直しは要りません。似た言葉が多いので、いまいる画面や場面に近い見出しから探すと早く見つかります。

### 課題を開くとき

| 画面に出る言葉 | こうしてください |
|---|---|
| 読み込めなかった課題 | 課題一覧の下に出る見出しです。読み込めなかった課題ファイルの名前と理由が並びます。その課題ファイルを直してから開き直してください |
| 課題一覧を読み込めませんでした | 課題一覧そのものが読めていません。設定の「利用者課題フォルダ」の場所を確かめてください |
| 模範回路エラー | 課題のお手本の回路が組み立てられませんでした。内蔵の課題で出たときは起動し直し、自分で作った課題で出たときは課題ファイルの書き方を見直してください |
| 設定を読み込めませんでした | 設定が読めていません。既定の設定のまま動いているので、設定の画面で入れ直してください |

### 練習中に赤い帯が出たとき

| 画面に出る言葉 | こうしてください |
|---|---|
| 予期しないエラーが発生しました | 赤い帯の「セッションをリセット」を押します。直らなければ「課題一覧へ戻る」を押します |
| セッションをリセット | 赤い帯のボタンです。押すと、いまの課題を作り直して続けられます |
| 課題一覧へ戻る | 赤い帯のボタンです。押すと、いまの課題を捨てて課題一覧の画面に戻ります |
| 作業を初期化して再開しました | 「セッションをリセット」を2回目に押したときに出る知らせです。作業が初期化されています |
| 盤を作り直せないため課題一覧へ戻りました | 部品点検・点検修復では2回目のリセットで作り直せないため、課題一覧に戻ります。課題をもう一度開いてください |
| 3D表示が中断しました。再表示して作業を続けられます。 | 「3D画面を再表示」を押してください。作業内容を保ったまま表示を作り直します |
| 3D画面を再表示 | 中断した3Dの表示を作り直すボタンです |
| シミュレーションでエラーが発生しました | 「セッションをリセット」を押してください。くり返すときは、いちど盤を初期状態に戻してみてください |
| プリロードが読み込まれていません | アプリを起動し直してください。直らないときは入れ直してください |
| #root が見つかりません | アプリを起動し直してください。直らないときは入れ直してください |

### テスターを使うとき

| 画面に出る言葉 | こうしてください |
|---|---|
| 通電中のΩ／導通測定 | 電源を切ってからテスターのΩ／導通レンジで測ってください |
| レンジ超過 | 測ろうとしている値に合ったレンジへ切り替えてください |
| 短絡状態での通電（電源保護動作） | 短絡（ショート）している配線を直してから、もう一度電源を入れてください |
| 電源操作の手順違反 | 電源は「① ブレーカ」→「② 電源スイッチ」の順に入れ、切るときは逆の順にしてください |
| アナログテスターのΩ／導通レンジのときだけ 0Ω 調整ができます | アナログテスターに切り替え、Ω／導通レンジにしてから0Ω調整をしてください（デジタルは自動で補正するので調整は要りません） |

### 配線と判定のとき

| 画面に出る言葉 | こうしてください |
|---|---|
| 1端子に3本目を接続 | 1つの端子には電線を2本までしかつなげません。中継端子台を使うか、つなぎ方を見直してください |
| 運転中の過電流（電源保護動作） | 短絡や配線の間違いが無いか確かめてから、保護復帰の手順で電源を入れ直してください |
| 線色ルール | 課題で決められた線色で配線し直してください |
| 1端子の本数 | 1つの端子に3本以上つないでいる箇所を減らしてください（中継端子台を使います） |
| 未使用部品 | 装着した部品を回路に組み込むか、使わないなら外してください |
| 禁則回路 | タイマの接点で自分のコイルを直接切らず、リレーを介してください |
| コイル極性 | コイルの＋とーの向きを確かめて配線し直してください |
| 電源操作手順 | 電源はON: ブレーカ→スイッチ、OFF: スイッチ→ブレーカの順で操作してください |
| 二段構成（PLC出力→中継リレー→表示灯） | PLCの出力はリレーのコイルへ、そのリレーの接点から表示灯へ、の2段で配線してください |
| PLC電源の独立 | 壁コンセント（AC100V）からだけ電源を取るように配線し直してください |
| I/O割付 | I/O割付表のとおりに、押ボタンのa接点をPLCの入力へ、PLCの出力をリレーのコイルへ配線し直してください |
| 盤に無い端子です | 盤にある端子から選び直してください |
| 配線帯までたどり着けません | 別の端子から配線するか、あいだの部品の配置を確かめてください |
| 部品の上を避けて通せません | 別の端子の組み合わせを選ぶか、あいだの部品を外してから配線してください |

### 元に戻す・やり直すとき

| 画面に出る言葉 | こうしてください |
|---|---|
| 元に戻せる操作がありません | これ以上「元に戻す」はできません。これより前の操作はありません |
| やり直せる操作がありません | これ以上「やり直し」はできません。「元に戻す」をしていないか、最後まで戻しています |

| 画面に出る言葉 | こうしてください |
|---|---|
| 変化する時刻がずれています | 押しボタンを押す・離すタイミングを課題の指示に合わせて見直してください |
| その時刻の点灯／消灯が逆です | 出ている信号のオン・オフが模範回路と違います。配線や部品を見直してください |
| 点く（切れる）はずの変化が起きていません | 模範回路では変わるはずの信号が変わっていません。配線や部品を見直してください |
| 起きないはずの変化が起きています | 模範回路には無い変化が出ています。配線や部品を見直してください |
| 見比べる信号が模範回路にありません | 課題の設定の問題です。指導者に確認してください |

## 画面が真っ黒になった

一番上に赤い帯が出て、その中に理由が書かれていることがあります。帯の「セッションをリセット」を押すと、いまの課題を作り直して続けられます。それでも直らないときは「課題一覧へ」を押してください。

「セッションをリセット」を押すと、多くの場合は作業がそのまま残ります。ただし、部品点検・点検修復のように盤を作り直せない練習では、作業は残らずに課題一覧へ戻ります（画面には「盤を作り直せないため課題一覧へ戻りました」と出ます）。作業が消えるのを防ぐために、判定の直前など、区切りのよいところでこまめに作業を保存しておくとよいです。

## 3Dが出なくなった

「WebGL」という3Dの仕組みがパソコン側で止まると、3Dの画面が描けなくなります。「3D表示が中断しました。再表示して作業を続けられます。」と出たら、「3D画面を再表示」を押してください。作業内容を保ったまま表示を作り直します。直らないときは作業を保存してから、アプリを閉じてもう一度起動してください。

他の重いソフトを閉じてから起動すると直りやすいです。ウィンドウを小さくすると軽くなることもあります。

## 作業ファイルが読めない

保存したファイルが壊れていたり、新しい版で保存したファイルを古い版で開こうとしたりすると読めません。理由が画面に出ます。

読めないファイルは上書きされないので、そのままの状態で残ります。別のパソコンや、そのファイルを保存したときのアプリで開き直すこともできます。前回の作業を自動で残す一時保存は1つだけで、新しく保存されると古いものは残りません。

## 説明書（PDF）が開かない

「説明書（PDF）が見つかりません。この画面の目次から同じ内容を読めます。」と出たときは、同じ内容をこの画面の目次から読めます。

PDFを見る道具（PDFビューア）が入っていないパソコンでは開けません。PDFファイルは、アプリを入れたフォルダの中の `resources` の中にあるので、そこから直接開くこともできます。

## 命令名やキーの割り当てについてのお断り

PLC の一部の命令の名前とキーの割り当ては、実際の機器の説明書を確かめられていないため、このアプリで決めた書き方です。実機と違う場合があります。

設定の「PLC（ラダー）」の欄には「一部の命令名・キー割当は実機マニュアル未確認のため本アプリの表記です。」という断りが出ています。違いが分かったときは、そのメーカーの表記だけが直されます。他のメーカーの表記はそのまま変わりません。
