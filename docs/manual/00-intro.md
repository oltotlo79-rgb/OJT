# はじめに

## このアプリでできること

電気教育ツールは、機械保全技能検定の電気系保全作業でつかう練習盤を、パソコンの画面の中にそのまま作ったものです。実際の盤と同じように、部品をのせて、電線をつないで、電気を流して、思ったとおりに動くかどうかを確かめられます。うまく動かないときは、どこがちがうのかを画面が教えてくれます。動かしたときの信号の動きは**タイムチャート**（どの信号がいつオンになったかを、横に時間を取って並べた図）で後から確かめられます。

実際の盤とちがうところが2つあります。1つは、電気は本物ではなく計算で流していることです。もう1つは、どれだけ間違えても盤をこわす心配がないことです。安心して何度でも練習できます。

このアプリでは、次の4つを練習できます。

1. 回路を組み立てる（モードB）: 部品をのせて電線をつなぎ、課題どおりに動く回路を作ります。
2. 部品を点検する（モードC1）: こわれたリレーやタイマを見つけます。
3. 回路を点検して直す（モードC2）: わざと間違えてある回路を見つけて直します。
4. PLCでプログラムを作る（モードD）: **ラダー図**（電気の回路図に似た形で、PLCの動きを書き表すプログラム）を作って盤を動かします。

ホームの画面では、練習のカードを押すとその練習の課題が並びます。右上の「設定」では音や課題の置き場所を変えられます。右上の「ヘルプ」を押すと、この説明書が画面の右から開きます。画面の図は「画面の見方」の「ホームの画面」にあります。

## ヘルプの使い方

わからないことがあったら、この説明書をアプリの中からすぐに開けます。どの画面でも「ヘルプ」ボタンを押すか、`F1` キーを押すと開きます。開いた中の「言葉で探す」に言葉を入れると、その言葉が出てくるところを探せます。「説明書（PDF）を開く」を押すと、同じ内容をパソコンの決まったソフトで開けます。くわしい場所と使い方は「画面の見方」の「画面の上の帯」にあります。

## 4つの練習の選び方

はじめての人は「回路を組み立てる」から始めてください。押しボタンを押すとランプが点いたままになる**自己保持**（押しボタンから指を離しても、そのままの状態が続くつなぎ方）という回路が、電気の仕事のいちばん基本になります。

| 練習 | どんな力がつくか |
|---|---|
| 回路を組み立てる（モードB） | 部品をのせて電線をつなぐ、いちばん基本の力 |
| 部品を点検する（モードC1） | テスターでこわれた部品を見つける力 |
| 回路を点検して直す（モードC2） | 動かない理由をさがして直す力 |
| PLCでプログラムを作る（モードD） | PLCのプログラムを作って動かす力 |

それぞれの課題にかかるだいたいの時間は、課題一覧の表に分単位で出ます。

課題には級（1級・2級・3級）があります。3級がいちばんやさしく、はじめての人におすすめです。級が上がるほど、自分で考えて確かめる場面が増えます。

## 画面の呼び名

この説明書では、画面の場所をいつも同じ言葉で呼びます。いちばん上に横に長く並んだボタンの列を「上の帯」、画面の右側にたてに並ぶ欄を「右の欄」、画面の下に出る細長い欄を「下の欄」と呼びます。

| 呼び名 | 場所 |
|---|---|
| 上の帯 | 画面のいちばん上に横に長く並ぶボタンの列 |
| 手順の案内 | 上の帯のすぐ下に出る、次に何をすればよいかの1行。画面では「手順」と出ます |
| 3Dの画面 | まん中の広いところ。練習盤を立体で見られます |
| 右の欄 | 画面の右側にたてに並ぶ欄。部品やテスターなど、いま使う道具が出ます |
| 下の欄 | 画面の下に出る細長い欄。タイムチャートなどが出ます |
| 状態の表示 | 3Dの画面の左上に出る、いまの状態の表示 |

それぞれの場所は「画面の見方」の「練習中の画面の並び」の図で、①から⑤の番号を付けて示しています。

このアプリは、三菱電機・オムロン・ジェイテクト・シャープの各社が作っている機器やソフトの「書き方」をまねた練習ができます。各社の名前は、どの書き方のことかを示すためだけに使っていて、各社との提携や後援をあらわすものではありません。
