# はじめに

## このアプリでできること

電気教育ツールは、機械保全技能検定の電気系保全作業を想定した練習用アプリです。3Dの練習盤に部品を装着し、配線・通電・測定を行いながら、回路の動作と故障診断を学べます。動作は**タイムチャート**（信号の変化を時間軸に沿って表示する図）で確認できます。

実際の電流を流さずに動作を計算するため、配線を間違えても機器を破損しません。繰り返し試し、予測と結果の違いを確認してください。実機では必要な安全手順を省略せず、電源を切ってから配線・部品交換を行います。

## ヘルプの使い方

分からないことがあったら、この説明書をアプリの中からすぐに開けます。どの画面でも「ヘルプ」ボタンを押すか、`F1` キーを押すと開きます。開いた中の「言葉で探す」に言葉を入れると、その言葉が出てくるところを探せます。「説明書（PDF）を開く」を押すと、同じ内容をパソコンの決まったソフトで開けます。詳しい場所と使い方は「画面の見方」の「画面の上の帯」にあります。

## 4つの練習の選び方

初めての人は「回路を組み立てる」から始めてください。押しボタンを押すとランプが点いたままになる**自己保持**（押しボタンから指を離しても、そのままの状態が続くつなぎ方）という回路が、電気の仕事の一番基本になります。

| 練習 | どんな力がつくか |
|---|---|
| 回路を組み立てる（モードB） | 部品を載せて電線をつなぐ、一番基本の力 |
| 部品を点検する（モードC1） | テスターで壊れた部品を見つける力 |
| 回路を点検して直す（モードC2） | 動かない理由をさがして直す力 |
| PLCでプログラムを作る（モードD） | PLCのプログラムを作って動かす力 |

それぞれの課題にかかるだいたいの時間は、課題一覧の表に分単位で出ます。

課題には級（1級・2級・3級）があります。3級が一番やさしく、初めての人におすすめです。級が上がるほど、自分で考えて確かめる場面が増えます。

## 画面の呼び名

この説明書では、画面の場所をいつも同じ言葉で呼びます。一番上に横に長く並んだボタンの列を「上の帯」、画面の右側にたてに並ぶ欄を「右の欄」、画面の下に出る細長い欄を「下の欄」と呼びます。

| 呼び名 | 場所 |
|---|---|
| 上の帯 | 画面の一番上に横に長く並ぶボタンの列 |
| 手順の案内 | 上の帯のすぐ下に出る、次に何をすればよいかの1行。画面では「手順」と出ます |
| 3Dの画面 | 中央の広いところ。練習盤を立体で見られます |
| 右の欄 | 画面の右側にたてに並ぶ欄。部品やテスターなど、いま使う道具が出ます |
| 下の欄 | 画面の下に出る細長い欄。タイムチャートなどが出ます |
| 状態の表示 | 3Dの画面の左上に出る、いまの状態の表示 |

それぞれの場所は「画面の見方」の[「練習中の画面の並び」](#sec-screens--練習中の画面の並び)の図で、①から⑤の番号を付けて示しています。

## 商標と表記について

このアプリは、三菱電機・オムロン・ジェイテクト・シャープの各社が作っている機器やソフトの「書き方」をまねた練習ができます。各社の名前は、どの書き方のことかを示すためだけに使っていて、各社との提携や後援を表すものではありません。

設定画面の「このアプリについて」を開くと、次の断り書きがそのまま読めます。

> MELSEC / MELSEC iQ-F / MELSOFT / GX Works3 は三菱電機株式会社、SYSMAC / CP1E / CP1L / CX-Programmer / CX-One はオムロン株式会社、TOYOPUC / PCwin は株式会社ジェイテクト、JW / JW300 / JW-300SP はシャープ株式会社の商標または登録商標です。各社の製品名は識別を目的としてのみ使用しており、提携・後援関係を示すものではありません。

もう1つの断り書きは、設定画面の「PLC（ラダー）」でメーカーを選ぶ欄のすぐ下に出ます。

> 一部の命令名・キー割当は実機マニュアル未確認のため本アプリの表記です。

各社のロゴや画面の写真はこのアプリに入っていません。
