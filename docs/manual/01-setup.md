# パソコンに入れる

## 動かすのに必要なもの

Windows 10 または Windows 11 の 64ビット版が動くパソコンなら使えます。特別な部品は要りません。画面は横 1280 点・たて 800 点より広ければ、全部の欄がきちんと並びます。

| 項目 | 必要なもの |
|---|---|
| OS | Windows 10 または Windows 11（64ビット版） |
| 画面の広さ | 横1280点・たて800点以上 |
| 空き容量 | 500MB程度 |
| インターネット | 不要（起動するときもふだん使うときも一切つなぎません） |

3Dの画面がなめらかに動かないときは、ウィンドウを小さくすると軽くなります。

## インストーラで入れる

配られたファイルのうち、名前が `-Setup.exe` で終わるほうがインストーラです。ダブルクリックすると入れ方をたずねる画面が出るので、案内にしたがって進めてください。管理者のパスワードは要りません。

1. ファイルをダブルクリックします。
2. 説明の画面を読んで「次へ」を押します。
3. 入れる場所を確かめます（変えたいときはここで変更できます）。
4. 「インストール」を押します。
5. 終わったらデスクトップにできたアイコンから起動します。

デスクトップとスタートメニューの両方にアイコンができます。

## 持ち運び版を使う

名前が `-Portable.exe` で終わるほうが持ち運び版です。ファイルはこの1つだけです。インストールせずに起動できます。

1. ファイルを使いやすい場所に置きます。
2. ダブルクリックして起動します。最初の画面が出るまで少し待ちます。

起動のたびに必要なファイルをパソコンの一時フォルダへ広げ、終了すると片付けます。配られたEXEを手作業で展開する必要はありません。

USBメモリに入れて持ち歩けます。ただし、設定と一時保存はパソコンの利用者フォルダに残るので、別のパソコンでは引き継がれません。

## 初回に出る青い画面

はじめて起動すると「Windows によって PC が保護されました」という青い画面が出ることがあります。これはこのアプリに署名が付いていないためで、こわれているという意味ではありません。

1. 「詳細情報」を押します。
2. 下に出る「実行」を押します。

2回目からはこの画面は出ません。

## インターネットにつながなくても使えます

このアプリは、起動するときも使っているときも、インターネットに一切つなぎません。工場の中のネットワークにつながっていないパソコンでも、そのまま全部の機能が使えます。

> **ヒント** 自動更新はありません。新しい版が出たときは、新しいインストーラや持ち運び版で入れ替えてください。

## 消すとき

インストーラで入れた場合は、Windows の「設定」の「アプリと機能」から消せます。持ち運び版は、アプリを閉じてから配られたEXEファイルを削除してください。

設定と一時保存は `%APPDATA%\電気教育ツール` に置かれます。消したいときは、このフォルダも合わせて消してください。
