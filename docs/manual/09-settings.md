# 設定

## 設定の画面

ホームの右上の「設定」から開きます。文字の大きさや音量などの設定は、変更すると保存されます。作成中の課題は下書きとして保存し、配布する課題ファイルは検証してから別に保存します。

設定の画面に出る項目は次のとおりです。

| 項目 | 種類 | できること |
|---|---|---|
| 文字と UI の大きさ | 選択欄 | 小（90%）・標準（100%）・大（115%）・特大（130%）から選びます。変更はすぐ反映されます |
| 見やすさ | 選択欄 | 標準・高コントラストを選び、文字と背景の区別をはっきりさせます |
| 利用者課題フォルダ | 文字入力 | 自分で作った課題を置くフォルダの場所を指定します |
| 効果音 | オン・オフ | 効果音を鳴らすかどうかを切り替えます |
| 音量 | つまみ | 効果音の大きさを変えます |
| 起動時に前回の作業の復元を確認する | オン・オフ | 前回の作業が残っているとき、復元するかどうかをたずねるかを切り替えます |
| 既定メーカー | 選択欄 | PLCの課題を開くときに最初に選ばれているメーカーを決めます |
| 列数はメーカーの既定に従う | オン・オフ | ラダーの表示列数をメーカーの既定に任せるかどうかを切り替えます |
| ラダーの表示列数 | 数字入力 | ラダー編集画面の接点の列数（8〜15）を決めます |
| 通電色はメーカーの既定に従う | オン・オフ | モニタ中の通電の色をメーカーの既定に任せるかどうかを切り替えます |
| 通電色 | 色選び | モニタ中に通電しているセルへ塗る色を決めます |
| 既定に戻す | ボタン | 既定メーカー・列数・通電色をまとめて既定値に戻します |

利用者課題フォルダに置いた課題ファイルは同梱課題と合流し、同じIDなら利用者側が優先されます。下の「課題の導入・作成」で内蔵課題を複製・編集・検証して課題ファイルとして保存できます。課題ファイルの書き方は「指導者向け」の章で説明します。

図では、①が「利用者課題フォルダ」、②が「効果音」、③が「既定メーカー」です。

## 自分で作った課題を読み込む

「課題の導入・作成」で、利用者課題フォルダの選択から複製、編集、検証、保存まで行えます。

「利用者課題フォルダ」に場所を入れておくと、そのフォルダの中の課題ファイルが課題一覧に並びます。内蔵の課題と一緒に出て、「利用者」という印が付きます。

何も入れないときの既定の場所は `%APPDATA%\電気教育ツール\content` です。「利用者課題フォルダを選ぶ」で保存先を選べます。インストーラ版・ポータブル版ともに「課題を複製」を使って雛形を取り出せます。

指定したフォルダが見つからないときは、課題一覧に「利用者課題フォルダが見つかりません。内蔵課題のみで動作します。」と出ます（フォルダのパスも一緒に出ます）。そのときは内蔵の課題だけで動きます。課題の作り方は「指導者向け」の章にあります。

## 課題作成の下書き

「課題の導入・作成」の変更は、入力が落ち着いてから約1秒で下書きに保存します。設定からホームへ移っても保持し、次回起動時にも復元します。記述が未完成でも保存できます。「課題下書き保存済み」の時刻を確認してください。「下書きを今すぐ保存」で待たずに保存でき、失敗した場合は「下書きの保存を再試行」を押せます。

「下書きを破棄…」は、確認したうえで作成中の内容を空にします。配布済みの課題ファイルには影響しません。配布するには、課題の検証と保存を行います。詳しい作図・検証手順は「指導者向け: 課題の作り方と配り方」を参照してください。

通常終了時は、練習中の作業と課題下書きの両方の保存完了を待ちます。保存失敗時は終了を中止し、修正や再試行に戻れます。強制終了や電源断の場合は、最後に保存が完了した状態まで復元できます。

## 音

リレーが動く音、テスターのブザー、警告の音が鳴ります。音を止めたいときや、大きさを変えたいときは「効果音」「音量」で変えます。

音は合成音で、音のファイルは入っていません。「効果音」を外すと、テスターのブザーも警告の音もすべて鳴らなくなります。

## PLCの既定のメーカー

「PLC（ラダー）」の「既定メーカー」で選びます。PLCの課題を開いたときに使う機種（メーカー）です。課題の機種もこのメーカーに合わせて開きます。練習中の課題には反映されません。練習中に変える場合は、課題画面の「表記切替」を使い、配線への影響を確認してください。

選べるのは三菱電機・オムロン・ジェイテクト・シャープの4社です。メーカー欄の下の「画面の見た目の前提」には、実機の資料で確認できていない表記・命令名・キー割当を表示します。

選び直したものをまとめて元へ戻したいときは、「既定に戻す」を押します。

## ラダーの見た目

「PLC（ラダー）」の中で、ラダー図の横に並ぶ「ラダーの表示列数」と、動きを見ているときに電気が通っているところに付く「通電色」を変えられます。「列数はメーカーの既定に従う」「通電色はメーカーの既定に従う」をどちらもオンにしておけば、選んだメーカーらしい見た目になります。

ラダー編集画面の接点列の数（8〜15）。メーカーの既定は 11 です。現在対応している4社で共通です。表示範囲の外にあるセルは削除されず、「表示列数の外にセルがあります」と表示します。

「通電色」は、モニタ中に通電しているセルへ塗る色です。「メーカーの既定に従う」のあいだは、選んでいるメーカーの色を使います。「既定に戻す」を押すと、既定メーカー・列数・通電色がまとめて既定値に戻ります。
