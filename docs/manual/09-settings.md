# 設定

## 設定の画面

ホームの右上の「設定」から開きます。変えた内容はすぐに保存され、次に起動したときも残ります。

設定の画面に出る項目は次のとおりです。

| 項目 | 種類 | できること |
|---|---|---|
| 利用者課題フォルダ | 文字入力 | 自分で作った課題を置くフォルダの場所を指定します |
| 効果音 | オン・オフ | 効果音を鳴らすかどうかを切り替えます |
| 音量 | つまみ | 効果音の大きさを変えます |
| 起動時に前回の作業の復元を確認する | オン・オフ | 前回の作業が残っているとき、復元するかどうかをたずねるかを切り替えます |
| 既定メーカー | 選択欄 | PLCの課題を開くときに最初に選ばれているメーカーを決めます |
| 列数はメーカーの既定に従う | オン・オフ | ラダーの表示列数をメーカーの既定に任せるかどうかを切り替えます |
| ラダーの表示列数 | 数字入力 | ラダー編集画面の接点の列数（8〜15）を決めます |
| 通電色はメーカーの既定に従う | オン・オフ | モニタ中の通電の色をメーカーの既定に任せるかどうかを切り替えます |
| 通電色 | 色選び | モニタ中に通電しているセルへ塗る色を決めます |
| 既定に戻す | ボタン | 既定メーカー・列数・通電色をまとめて既定値に戻します |

各行の下には、その項目の説明文が出ています。「利用者課題フォルダ」の説明は次のとおりです（次の節でくわしく説明します）。

```
利用者課題フォルダに置いた課題JSONは同梱課題と合流し、同じIDなら利用者側が優先されます。インストール先の resources/content/assemble/ が同梱課題の実体なので、そこからコピーして書き換えると雛形として使えます（消してもアプリ内蔵の課題で起動します）。
```

「既定メーカー」の説明は「モードDの課題を開いたときに使う機種（メーカー）です。課題の機種もこのメーカーに合わせて開きます。」です。「ラダーの表示列数」の説明は「ラダー編集画面の接点列の数（8〜15）。メーカーの既定は 11 です。」（数はいま選んでいるメーカーの既定にあわせて変わりますが、三菱・オムロン・ジェイテクト・シャープはいまのところどれも11です。数字を除いた文言そのものは「ラダー編集画面の接点列の数（〜）。メーカーの既定は」で固定です）。「通電色」の説明は「モニタ中に通電しているセルへ塗る色です。「メーカーの既定に従う」のあいだは、選んでいるメーカーの色を使います。」です。

図では、①が「利用者課題フォルダ」、②が「効果音」、③が「既定メーカー」です。

## 自分で作った課題を読み込む

「利用者課題フォルダ」に場所を入れておくと、そのフォルダの中の課題ファイルが課題一覧に並びます。内蔵の課題と一緒に出て、「利用者」という印が付きます。

何も入れないときの既定の場所は `%APPDATA%\電気教育ツール\content` です。内蔵の課題そのものは、アプリを入れたところの `resources/content/assemble/` などに入っているので、そこからコピーして書き換えると雛形として使えます。

指定したフォルダが見つからないときは、課題一覧に「利用者課題フォルダが見つかりません。内蔵課題のみで動作します。」と出ます（フォルダのパスも一緒に出ます）。そのときは内蔵の課題だけで動きます。課題の作り方は「指導者向け」の章にあります。

## 音

リレーが動く音、テスターのブザー、警告の音が鳴ります。音を止めたいときや、大きさを変えたいときは「効果音」「音量」で変えます。

音は合成音で、音のファイルは入っていません。「効果音」を外すと、テスターのブザーも警告の音もすべて鳴らなくなります。

## PLCの既定のメーカー

「PLC（ラダー）」という見出しの中の「既定メーカー」で選びます。PLCの課題を開くときに、最初に選ばれているメーカーを決める欄で、下には「モードDの課題を開いたときに使う機種（メーカー）です。課題の機種もこのメーカーに合わせて開きます。」という説明が出ます。開いたあとでも表記切替で変えられます。

選べるのは三菱電機・オムロン・ジェイテクト・シャープの4社です。選んだメーカーの下には、画面の見た目の前提として、いま選んでいるメーカーの見た目のうち何が実機の資料で確認できていないのかが一覧で出ます。「一部の命令名・キー割当は実機マニュアル未確認のため本アプリの表記です」という断りも、この欄のすぐ下に出ています。

選び直したものをまとめて元へ戻したいときは、「既定に戻す」を押します。

## ラダーの見た目

「PLC（ラダー）」の中で、ラダー図の横に並ぶ「ラダーの表示列数」と、動きを見ているときに電気が通っているところに付く「通電色」を変えられます。「列数はメーカーの既定に従う」「通電色はメーカーの既定に従う」をどちらもオンにしておけば、選んだメーカーらしい見た目になります。

「ラダーの表示列数」の説明は「ラダー編集画面の接点列の数（8〜15）。メーカーの既定は 11 です。」です。列の数は8〜15のあいだで決められます。表示する列数を減らして、いままで置いていた記号が格子の外にはみ出しても記号は消えません。「表示列数の外にセルがあります」という注意とともに、そのまま残ります。

「通電色」の説明は「モニタ中に通電しているセルへ塗る色です。「メーカーの既定に従う」のあいだは、選んでいるメーカーの色を使います。」です。「既定に戻す」ボタンを押すと、既定メーカー・列数・通電色がまとめて既定値に戻ります。
