# 作業を保存する・続きからやる

## 作業ファイルに保存する

とちゅうでやめたいときは、上の帯の「⋯」を押し、「作業ファイル」の中の「作業を保存」を選びます。保存する場所と名前をたずねる窓が出るので、好きなところに保存してください。

保存されるのは、載せた部品・つないだ電線・タイマの時間・ラダー図・回路図の下書き・テスターの状態・かかった時間・危険な操作の回数です。部品点検の答え、点検・修復の指摘なども、そのモードで作業していれば一緒に保存されます。ファイルの拡張子は `.ojtw` です。

## 保存した作業を読み込む

「⋯」から「作業ファイル」の中の「作業を読込」を選び、保存したファイルを選びます。いま開いている課題がある場合は、「いまの作業を破棄して別の課題の作業ファイルを開きますか？」とたずねて、捨ててよいかを先に確認します。

壊れていたり、新しい版で保存したファイルを古い版で開こうとしたりすると読み込めません。そのときは画面に理由が出ます（形式が不正、形式バージョンが無い、新しいバージョンで作られている、課題IDや盤の状態が無い、など）。理由を読んで、別のファイルを選ぶか、そのファイルを保存したパソコンで開き直してください。古い版で保存したファイルも、多くの項目は無くても課題を最初から開き直すだけなので読めます。

## 前回の作業を復元する

アプリは30秒ごとに、いまの作業をこっそり控えています。前に閉じたときの作業が残っていると、次に起動したときに「前回の作業を復元しますか？」とたずねます。

たずねる画面には「保存時刻」のほか、どの練習（モード）だったか、どの課題だったか、どれくらい進んでいたか（経過時間）が出ます。「復元する」を選ぶとその続きから、「復元しない」を選ぶと最初から始められ、控えは消えます。復元すると、それまでの危険な操作の回数も「復元前の危険操作」として引き継がれ、操作ログに残ります。

この確認は、設定の「起動時に前回の作業の復元を確認する」を外すと出さなくできます。外した場合、控えがあっても黙って最初から始まります。
