# 作業を保存する・続きからやる

## 作業ファイルに保存する

途中でやめるときは、上の帯の「⋯」→「作業ファイル」→「作業を保存」を選び、場所と名前を指定します。拡張子は `.ojtw` です。手動保存は、保存先を選ぶ窓を開いた時点の作業を保存します。窓を開いた後の変更は自動保存で別に記録します。

| 項目 | 保存・復元する内容 |
|---|---|
| 課題 | 課題IDと、保存時点の課題定義の複製 |
| 盤 | 装着部品、配線、線色、タイマ設定、拡張盤設定、線番・注記・配線経路 |
| PLC | ラダー、メーカー・機種、デバイスコメント、ウォッチ登録、自由課題のI/O割付 |
| 点検 | C1の解答と点検対象、C2の故障条件・指摘・修復状態 |
| 学習記録 | 経過時間、危険操作の累計、ヒント段階、回路図を開いた回数 |
| 測定 | テスターの設定とプローブ、保存ボタンで固定した測定値、診断メモ |
| 回路図 | 自分で編集した下書き |

読み込むと、盤電源はOFF、PLCはSTOPから始まります。CPUの実行途中の内部値・タイマ経過・カウンタ現在値、入力強制、停止条件、直前のライブ波形、Undoの履歴は再開しません。配線を確認し、必要なときに変換・モニタ・RUNを行ってください。

## 保存した作業を読み込む

「⋯」→「作業ファイル」→「作業を読込」を選びます。いまの作業に未保存の変更があれば、同じ課題IDのファイルでも「いまの未保存の作業を破棄して、作業ファイルを開きますか？」と確認が出ます。「保存して開く」は現在の作業を保存してから読み込み、「保存せず開く」は現在の未保存変更を破棄して読み込みます。「取消」では今の作業を続けられます。

ファイルは全体を検証してから読み込みます。不正な盤・端子・ラダー・故障情報などがあれば、理由を表示し、現在の作業を残します。

| ファイル | 読み込み時の扱い |
|---|---|
| これまでの形式バージョン1 | 必須の盤とモード情報が正しければ読めます。追加された測定記録やウォッチなどが無い場合は空から始めます |
| 保存時の課題定義を含むファイル | 同じIDの課題が後で更新されても、保存した課題の条件を使います。現在の定義と異なる場合は通知します |
| 課題定義を含まない旧ファイル | 現在導入されている同じIDの課題を使います。課題が見つからなければ導入し直してください |
| C2の故障条件など必須情報が欠けるファイル | 違う故障として再開しないよう、読み込みを断ります |
| 本アプリより新しい形式バージョン | 対応する新しいアプリで開いてください |

配線は最大200本、ラダーは最大64回路ブロックです。上限を超えたファイルは、途中だけを切り捨てて読み込むことはありません。

旧版で65個以上の回路ブロックを保存していた場合は、「救出用ファイルを書き出す」を選べます。保存先に新しい `ojt-recovery-...` フォルダを作り、全内容の `original.ojtw` と、64ブロックずつの `part-001.ojtw` などを保存します。元のファイルと現在の作業は変わりません。分割ファイルを読み込んで内容を確認し、必要なブロックを64個以内に整理してください。分割により前後のブロックの依存関係が変わるので、変換・動作確認後に別名で保存し、整理が終わるまで原本を保管してください。

## 自動保存と通常終了

作業変更が落ち着いてから約1.2秒後に自動保存します。経過時間は30秒ごとにも記録します。画面右下の「自動保存待ち」「自動保存中…」「自動保存済み」と保存時刻で確認できます。保存に失敗したら理由と再試行の操作が出ます。

通常のウィンドウ終了では、最新の変更の保存完了を待ってから閉じます。保存できない場合はアプリを閉じず、再試行や手動保存へ戻ります。電源断や強制終了から復元できるのは、最後に保存が完了した状態です。

## 前回の作業を復元する

起動時に自動保存が見つかると「前回の作業を復元しますか？」と表示します。保存時刻・練習モード・課題・経過時間を確認し、「復元する」で再開します。「復元しない」を選ぶと控えを削除します。ログ欄の「復元前の危険操作」で確認できる累計は、その後の操作で増えた分と合わせて記録します。

設定の「起動時に前回の作業の復元を確認する」を外すと、起動時の復元確認を表示しません。

## 画面や計算が止まったとき

エラー表示の再開操作は、配線・ラダー・解答・指摘・測定記録を保持したまま表示と計算を作り直します。繰り返し再開しても課題を初期状態へ戻しません。電源とCPUの実行状態は初期化するので、安全な状態から動作を確認してください。「もう一度」は課題のやり直しなので、途中の作業を残したい場合は先に保存してください。
