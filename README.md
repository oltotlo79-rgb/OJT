# 電気教育ツール

機械保全技能検定 電気系保全作業の実技（課題1・課題2）と、有接点シーケンス回路の組立・
PLCラダーの作成を、パソコン上の3D練習盤とシーケンス図エディタで学ぶための教育用デスクトップ
アプリケーションです。

## これは何か

- **モード B（回路組立）**: 部品を配線して有接点シーケンス回路を組み立てる練習課題。
- **モード C1（部品点検）**: テスタで部品単体（抵抗・コイルなど）の良否を判定する課題。
- **モード C2（回路点検・修復）**: 通電状態の回路から故障箇所をテスタで特定し、白線で
  修復する課題。
- **モード D（PLCラダー）**: 三菱電機（MELSEC iQ-F）・オムロン・ジェイテクト・シャープの
  4メーカーのPLCを模したラダー編集画面で、入出力の配線とラダープログラムを作成する課題。
- **回路図エディタ**: 有接点シーケンス回路をシーケンス図として描き、机上で検算してから
  3D盤の配線ガイドに従って配線する練習ができます。

内蔵課題は合計 **72題**（モード B 20 / C1 12 / C2 20 / D 20）を同梱しており、追加の
ダウンロードなしにオフラインで練習を開始できます。各課題には級（3級／2級／1級）のほか、
同じ級の中の難易度（1〜5）が付いています。

## ヘルプとPDF取扱説明書

取扱説明書はアプリに同梱しています。オンラインの文書を見に行く必要はありません。

- **アプリ内のヘルプ**: 画面の「ヘルプ」、または `F1` キーで引き出しが開きます。もくじから
  たどるほか、「言葉で探す」に語句を入れて本文を検索できます。
- **PDF の取扱説明書**: 同じ内容を PDF でも同梱しています。ヘルプの
  「説明書（PDF）を開く」を押すと、OS の既定のビューアで開きます。

## 動作環境

- Windows 10 / 11（x64）
- コード署名なし（unsigned）
- 完全オフラインで動作します（外部への通信は行いません）

## 入手と導入

配布物は次の2種類です。用途に応じて使い分けてください。

- **NSISインストーラー**（`電気教育ツール-1.0.0-x64.exe`）: 通常のインストール用。実行すると
  スタートメニュー登録などを伴ってインストールされます。管理者権限は不要です。個人利用・
  複数端末への展開に向いています。
- **ポータブル版**（`電気教育ツール-1.0.0-x64.zip`）: 展開するだけで実行できます。
  インストールせず一時的に試す場合や、管理者権限が無い環境に向いています。

配布物は `pnpm --filter @ojt/desktop dist` で `apps/desktop/release/` に生成されます
（`release/artifacts.md` にファイル名・サイズ・SHA256 の一覧が書き出されます）。本READMEは
配布ファイルの置き場所やダウンロードURLを案内するものではありません。入手方法は配布時の
案内に従ってください。

## 初回起動時の注意（Windows SmartScreen）

本ソフトウェアはコード署名を行っていないため、インストーラーまたは実行ファイルを初回起動した
際に「Windows によって PC が保護されました」という SmartScreen の警告が表示されることが
あります。その場合は次の手順で起動してください。

1. 警告画面の「**詳細情報**」をクリックする
2. 表示された「**実行**」ボタンをクリックする

インストーラーの説明画面にも同じ手順を掲載しています。

## オフラインについて

本ソフトウェアは起動時・実行時ともに外部へ一切通信しません。自動更新の機能もありません。
更新は新しいインストーラーの配布によって行います。ネットワークに接続されていない環境
（オフラインのWindows PCなど）でも、インストールから課題の練習まで問題なく行えます。

## 開発者向け

このリポジトリは pnpm ワークスペースです（Node.js 22 以上。`.npmrc` の `engine-strict=true`
により対応外の Node.js では `pnpm install` が失敗します）。開発の作法全般（生成物の扱い・
`BASELINE` の下げ方・git の作法など）は `CONTRIBUTING.md` にまとめています。

```
pnpm install
pnpm verify              # = typecheck + lint + -r test。コミット前に1回通す
pnpm --filter @ojt/desktop dev
pnpm --filter @ojt/desktop build
pnpm --filter @ojt/desktop e2e
pnpm --filter @ojt/desktop dist
```

**注意（`e2e` の直後に `dist` を走らせない）**: `pnpm --filter @ojt/desktop e2e` は
`manual-shots.spec.ts` が追跡下の `docs/manual/images/` を**撮り直して上書き**します。
`dist` はその画像を取扱説明書PDFへ焼き込むため、**`e2e` の後・`dist` の前には必ず
`git status --short` が空であることを確認してください**（空でなければ
`git checkout -- docs/manual` で撮り直し分を戻します）。空でないまま `dist` すると、
コミットしたツリーではなく撮り直した図で配布物が作られます。`e2e` と `dist` は共有の
作業ツリーではなく使い捨ての worktree で行ってください。詳しい手順は `CONTRIBUTING.md`
「§6 `dist` の前に作業ツリーを清浄にする」を参照してください。
